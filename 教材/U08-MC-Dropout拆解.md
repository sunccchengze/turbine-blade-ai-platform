# 第 8 单元 · MC Dropout 拆解

读完本单元，你必须能：

1. 拆开 **M / C / Dropout** 三个词；
2. 写出 \\(\\mu,\\sigma\\) 和名义带 \\(\\mu\\pm1.96\\sigma\\)；
3. 说出**生产端是预计算常数 σ**、ONNX 没有 Dropout 算子；
4. 区分 **MC 估计量收敛**（\\(T=100\\) 够）和**覆盖率没校准**（U09 讲）。

对照图：`docs/lecture-figs/q4-mc-dropout-mechanism.svg`。覆盖率与加宽在 **U09**（不是 U10）。

**桥（不需要重学）：** U06（Dropout、激活、权重、eval()、inverted dropout、BatchNorm）、U01（代理、留出集）；高中：均值、标准差、正态分布。

**本章依赖链：**

```text
Monte Carlo = 随机抽样逼近 → 面具 z → 有效权重
   → 前向 T=100 次 → μ = 样本均值、σ = 样本标准差
   → 1.96（标准正态 0.975 分位）→ 名义带 μ±1.96σ
   → SE = σ/√T → T 够不够
   → 认知不确定 vs 偶然不确定 → 变分包装（名字）
   → 生产端：常数 σ（ONNX 无 Dropout）
```

## 8.1 拆词：M、C、Dropout 各干什么

| 词 | 拆开 | 一句操作定义 |
|---|---|---|
| Monte | 蒙特 | 摩纳哥赌场地名，算法只借「**随机抽样**」这个意思 |
| Carlo | 卡洛 | 同一词的后半。合起来（Monte Carlo，MC）：用随机抽样逼近很难直接算的量 |
| Dropout | 丢弃 | 以概率 \\(p=0.1\\) 把**激活**乘 0（U06 复习）。权重 \\(W\\) 还在磁盘上 |
| 面具 | mask \\(z\\) | 每一层独立抽的 0/1 随机数。keep 概率 \\(1-p=0.9\\) |
| 有效权重 | effective weights | 被面具改写之后，**这一次前向真正用到的通路** |
| 启发式不确定带 | heuristic band | 法定名称。**不是校准的 95% CI** |

**Monte Carlo（MC 估计量收敛）。** 抽样次数 \\(T\\to\\infty\\) 时，样本均值收敛到期望（高中数学的「大数定律」思想）。这是本章**唯一**能说「收敛」的地方。判据：标准误差 \\(\\mathrm{SE}(\\mu)=\\sigma/\\sqrt{T}\\)。

**Dropout**（Srivastava 2014）：训练期正则（U06）。乘 0 的是激活，不是把 \\(W\\) 从磁盘删掉。

**MC Dropout**（Gal & Ghahramani, ICML 2016）：推理时也**不关** Dropout，同一 \\(x\\) 前向 \\(T\\) 次，每次换面具。均值当预测，标准差当不确定度。论文包装：Bernoulli 变分分布上的蒙特卡洛积分（**包装可以后懂；答辩先会操作**——Bernoulli 变分分布 = 用「以概率 p 丢弃」这类 0/1 分布近似权重的后验，名字级即可）。

**为什么不能叫「校准的 95% CI」。** 校准 = 实测覆盖率要真到 95%（U09 定义覆盖率）。实测只有 65%（η），所以它只能叫**启发式带**。

## 8.2 操作：对着残差网走 100 次

**依赖链：** 伪代码 → \\(T=100\\)、\\(p=0.1\\) → μ/σ 公式 → 生产端常数 σ → 常数 σ 的后果。

**参数与位置。** \\(p=0.1\\)，\\(T=100\\)。残差块里 Dropout 在两 Linear 之间、ReLU 之后（U06）。输出层通常没有。

```
for t = 1 … 100:
    z^(t) ~ Bernoulli(0.9)    # 各层位置独立抽面具
    y^(t) = f(x ; θ ⊙ z^(t))  # 用被面具改过的权重前向一次
μ = mean(y^(t));  σ = sample std(y^(t), ddof=1)
```

\\(\\odot\\) = 逐元素相乘（面具乘到权重上）；ddof=1 = 样本标准差用 \\(T-1\\) 除（无偏习惯）。常规推理 `eval()` 关 Dropout，一点定死，σ 变成 0。

**公式：**

\\[
\\mu(x)=\\frac1T\\sum_t y^{(t)}(x),\\quad
\\sigma(x)=\\sqrt{\\frac1{T-1}\\sum_t(y^{(t)}-\\mu)^2}
\\]

**生产端真相（答辩必背）。** 生产 ONNX **没有** Dropout 算子。`predict_with_uncertainty` 用训练期平均 σ 常数表：**π 0.0064，η 0.0010，ṁ 0.0611**。`n_mc_samples` 被接受但**不生效**。网页上每个点**并没有**抽 100 次。

**两个后果。** ① 所有点的带一样宽——常数带**不能给点排序**（谁更不确定分不出来）。② 所有 \\(y^{(t)}\\) 几乎一样时：有效权重附近输出平坦，σ 小——**σ 小不等于一定准**。

## 8.3 公式：1.96 从哪来；T 够不够

**依赖链：** 1.96 = 标准正态 0.975 分位 → 两个前提都不干净 → SE → T=100 够 → 认知/偶然 → 变分窄 → fig14 r≈0.027 → 三句复述。

**1.96 的来历。** 标准正态分布（均值 0、标准差 1 的正态分布）的 **0.975 分位**：正态里 95% 的概率落在 ±1.96 之内。于是名义带：

\\[
I(x)=\\big[\\mu-1.96\\sigma,\\ \\mu+1.96\\sigma\\big]
\\]

**它悄悄假设了两件事**：① \\((y-\\mu)/\\sigma\\sim\\mathcal N(0,1)\\)（标准化误差是标准正态）；② σ 没有系统性偏小。**这两个前提本项目都不干净**——这正是 U09 覆盖率只有 65% 的原因之一。

**T 够不够。** \\(\\mathrm{SE}(\\mu)=\\sigma/\\sqrt{T}\\)。\\(T=100\\) 时 SE ≈ \\(0.1\\sigma\\)——样本均值本身已经够稳。再加到 T=10000，SE 更小，**覆盖率不会因此到 95%**：失败不是抽样次数，是把 1.96 当成了校准过的数。

**认知 vs 偶然（两个名词一次说清）。** Dropout 只扰动有效权重 = **认知不确定**（epistemic）：换一套还说得通的参数，预测会怎么变。它**不建模**数据本身的跳（**偶然/aleatoric**：激波位置的随机性这类，除非另做「异方差头」——名字，输出层加一个专门预测 σ 的头）。Gal 的变分族窄，常**低估**宽度；变分近似不能画等号成真后验。

**fig14 的判决数字。** η 上 σ 与 \\(|\\mathrm{err}|\\)（误差绝对值）相关约 **0.027**——带宽几乎不跟踪谁更难。\\(\\bar\\sigma_\\eta=0.0010\\) 相对窄带 0.045（U01）约 **2%**：η 的 σ 特别小，**仍可能更不可信**。

**主动学习（U12 细讲）不能只看 σ**：会漏掉 σ 小但误差大的点。常数带不能点排序。

**三句复述必须出现：面具、有效权重、T=100。**
