# 第 2 单元 · 相对运动与欧拉做功

离开本单元，你必须能做四件事：说出 C、W、U 各是谁在看；把 \(M_\mathrm{rel}\) 写成 \(|W|/a\) 并说明 \(T\) 是静温；写出最简欧拉式并指出页面那格 \(\Delta h_0\) **不是**它；指出滑块上的 \(P\) 是背压，文件在预测页。

U01 已会：压气机、转子、\(\pi,\eta,\dot m\)、总压、等熵。本章新对象：转起来之后的速度怎么拆、功从哪来、两个工况旋钮是什么。

高数里的向量加减、角速度 \(\times\) 半径，直接当桥。周向、预旋、特性线、422，当场定义。

## 2.1 画面：三个人看到三种速度

![进口速度三角形](figures/U02-velocity-triangle.svg)

先认词：

| 中文 | 符号 | 一句操作定义 |
|---|---|---|
| 机匣 | casing | 不转的外壳。站在机匣上 = 站在实验室地面上 |
| 角速度 | \(\Omega\) | 转子转多快。本项目单位必须是 rad/s。1 rpm \(= 2\pi/60\) rad/s |
| 半径 | \(r\) | 从转轴到该点的距离，单位 m。叶尖 \(r\) 大，轮毂 \(r\) 小 |
| 牵连速度 | \(\mathbf{U}\) | 固体自己因旋转而具有的线速度，\(U=\Omega r\)，方向沿周向 |
| 周向 | tangential / \(\theta\) | 顺着转动的方向，既不是轴向（气流总方向），也不是径向（沿叶高往外） |
| 绝对速度 | \(\mathbf{C}\) | 站在机匣上看气体的速度 |
| 相对速度 | \(\mathbf{W}\) | 站在叶片上看气体的速度 |
| 速度三角形 | velocity triangle | 把 \(\mathbf{C}=\mathbf{W}+\mathbf{U}\) 画成一个三角形。进口一张，出口再一张 |
| 相对马赫数 | \(M_\mathrm{rel}\) | \(\|W\|/a\)。跨音速转子「跨」的主要是这个，不是 \(|C|/a\) |
| 叶尖 / 轮毂 | tip / hub | 叶片最外缘 / 最靠近轴。叶高 100% / 0% |

**画面。** 叶片在转。你有两个合法的观察点。

站在机匣上：看见气体以 \(\mathbf{C}\) 过来，叶片以 \(U=\Omega r\) 横着扫过去。  
站在某片叶子上：叶子相对你是停的，气体以 \(\mathbf{W}\) 扑过来。

高数向量加法在这里就是一句话：

\[
\mathbf{C}=\mathbf{W}+\mathbf{U}
\]

三个量必须在**同一点、同一时刻**谈。进口画一次，出口再画一次，因为折转之后 \(\mathbf{W}\) 的方向变了，\(C_\theta\) 通常也变了。

**拆词：为什么要拆成相对。** 激波、附面层长在叶片通道里，通道是跟着叶子走的。判断通道里会不会立激波，看的是相对来流是否超音，也就是 \(M_\mathrm{rel}\)。

\[
M_\mathrm{rel}=\frac{|W|}{a},\qquad a=\sqrt{\gamma R T}
\]

\(a\) 是当地声速。\(T\) 必须是**静温**，不是总温。用总温会把 \(a\) 算大，把马赫算小。\(\gamma\) 空气常取 1.4，\(R\) 空气常取 \(287\,\mathrm{J/(kg\cdot K)}\)。

**操作：叶尖为什么先超音。** \(U=\Omega r\)。同一 \(\Omega\)，叶尖 \(r\) 大，\(U\) 大，通常 \(|W|\) 也更大，所以叶尖 \(M_\mathrm{rel}\) 先过 1。Rotor 37 公开设计值大约叶尖 \(M_\mathrm{rel}\approx 1.48\)。这是文献/基准的典型数，**不是**我们 SU2 跑出来的数，不能当 E4。

相对超音、绝对亚音可以同时发生：\(U\) 很大时，\(|W|\) 可以大于 \(a\)，而 \(|C|\) 仍小于 \(a\)。跨音速转子常见这种组合。

**数据。** 本项目 \(\Omega\) 大约 1620–1800 rad/s。设计转速量级约 17188.7 rpm。换算：

\[
\Omega=\mathrm{rpm}\times\frac{2\pi}{60}\approx 17188.7\times 0.10472\approx 1800\,\mathrm{rad/s}
\]

有人把滑块标成 rpm，\(U\) 会错大约 \(2\pi/60\approx 9.55\) 倍。仓库里必须是 rad/s。见 `data_card.md`。

**边界。** \(\Omega\) 拉高，同样半径上 \(U\) 变大，\(M_\mathrm{rel}\) 升高，通道里激波会变强（U03）。所以「转得欢三项一起好」物理上不可信。代理若在训练盒子边上吐出三项同升，先怀疑外推，不要写成物理发现。

仓库指认：转速范围与单位在 `data_card.md`。1.48 写进信必须带「公开基准设计值」。

## 2.2 欧拉做功：功从周向动量来

先认词：

| 中文 | 符号 | 一句操作定义 |
|---|---|---|
| 滞止焓 / 总焓 | \(h_0\) 或 \(h_t\) | 把气等熵刹停时的焓。压气机做功主要抬它 |
| 欧拉做功方程 | Euler work | 轴流最简：单位质量 \(\Delta h_0=U_2C_{\theta2}-U_1C_{\theta1}\) |
| 周向分速 | \(C_\theta\) | 绝对速度 \(\mathbf{C}\) 在周向的分量 |
| 预旋 | pre-swirl | 进口已经有的 \(C_{\theta1}\)。进口导叶常用来给预旋 |
| 理论功 | Euler work | 不计损失时，动量矩变化对应的焓升 |
| 等熵焓升 | isentropic \(\Delta h_0\) | 同样 \(\pi\)、过程等熵时该有的焓升。页面那格是这个 |
| PINN | Physics-Informed NN | 把微分方程残差写进损失。本章还只需要记住：页面公式 \(\neq\) PINN |

**画面。** 叶片扫过去，给气体一个沿周向的动量。气体的滞止焓升高。这是**做功**，不是摩擦把动能耗成热——摩擦也涨焓，但那是损失，效率会掉。

**公式。** 对轴流级，忽略径向掺混和间隙泄漏，单位质量：

\[
\Delta h_0=U_2 C_{\theta 2}-U_1 C_{\theta 1}
\]

下标 1 进口，2 出口。量纲是 J/kg，也就是 \(\mathrm{m}^2/\mathrm{s}^2\)。

进口若几乎没有预旋，\(C_{\theta1}\approx 0\)，则 \(\Delta h_0\approx U_2 C_{\theta2}\)。预旋 \(C_{\theta1}>0\) 时，减项变大，同样出口周向速度下理论功变小。

它和页面那格不是同一个量：

| | 欧拉 \(\Delta h_0\) | 预测页那格 \(\Delta h_0\) |
|---|---|---|
| 来源 | 速度三角形 / 动量矩 | \(c_p T_{t1}(\pi^{(\gamma-1)/\gamma}-1)\) |
| 是什么 | 叶片实际传给气的功（理想化、无损失时是理论功） | **等熵**过程达到同一 \(\pi\) 所需的焓升 |
| 本仓库 | **没有**作为网络输出，也没有进损失 | 前端用预测出来的 \(\pi\) 现场算的参考 |

**操作：为什么网络不可能「内部在用欧拉」。** 欧拉式要进出口的 \(U\) 和 \(C_\theta\)。特征里没有 \(C_\theta\) 场，也没有叶尖半径这个旋钮，只有坐标的统计量。网络看见的是 74 个统计数（构造在 U05）。它学的是统计量到三个标量的拟合，不是在积分动量矩。

「我接了欧拉做功」若让人听成「网络里嵌了欧拉方程」，就越档。给郭老师的信第 4 稿已经改成：页面参考；网络只有输出边界惩罚。

**数据。** 页面公式与 U01 相同：\(c_p=1.005\,\mathrm{kJ/(kg\cdot K)}\)，\(T_{t1}\) 冻在 288.15 K。它随预测 \(\pi\) 单调，**不随 \(\eta\) 变**。这不是 bug，是定义：等熵焓升只由压比（加假定的进口总温）决定。

**边界。** 欧拉功升高，\(\pi\) 倾向升高；激波变强时 \(\eta\) 可以掉。所以只提高 \(U\)、不改折转，\(\pi\) 与 \(\eta\) 不必同号。理论功与实际滞止焓升之差，工程上归到损失。

仓库指认：页面计算在 `frontend/src/pages/PredictPage.jsx`（约 `1.005 * 288.15 * (π^0.2857 - 1)`）。

## 2.3 两个工况旋钮：\(\Omega\) 和背压 \(P\)

先认词：

| 中文 | 符号 / 英文 | 一句操作定义 |
|---|---|---|
| 工况 | operating condition | 这台机器现在跑在哪一点：转多快、下游堵多紧 |
| 背压 | back pressure \(P\) | **出口静压**，用来节流。不是进口总压。旧页签错过 |
| 特性线 | speed line | 固定转速，改背压，得到一条 \(\dot m\)–\(\pi\) 曲线 |
| 堵塞边 | choke | 喉部到声速，再降背压 \(\dot m\) 几乎不再增加 |
| 失速边 | stall | 流量过小、分离扩大、接近失速的一端。\(\dot m\) 比堵塞边更小 |
| 插值 | interpolation | 在训练见过的 \(\Omega,P\) 盒子里问代理 |
| 外推 | extrapolation | 问到盒子外面。本项目部署上应拒绝 |
| 422 | HTTP 422 | 输入越出 `FEATURE_STATS` 时接口拒绝，不给数 |
| abstain | 弃权 | 系统选择不回答。422 是它的雏形 |

**画面。** 实验台上改工况，通常动两个东西：电机转速，和出口节流阀。转速对应 \(\Omega\)。节流阀把下游堵住一点，出口静压升高，这就是加背压。

**操作。** 输入里真正的工况只有这两个，不是从三万个表面点算出来的：

- \(\Omega\)：转速，rad/s  
- \(P\)：背压，Pa  

特性图：横轴 \(\dot m\)（或修正流量），纵轴 \(\pi\)，一条转速一条线。沿一条线移动 = 改背压。背压升高 → 通常流量下降，靠近失速边；背压降低 → 流量上升，靠近堵塞边。

**数据。** 代理只在训练见过的 \(\Omega,P\) 范围内插值。超出 `FEATURE_STATS` 的 min–max，接口应返回 422，不吐数。这是 abstain 的雏形：承认自己不该回答，而不是硬外推。证据档要到 U11 才系统讲；现在先记住：422 是工程策略，不是 E4。

**边界。**

- 没有把进口总温、进口总压当独立标签去扫完整特性面，所以不能说「全工况智能优化」。
- \(U=\Omega r\) 需要半径。坐标统计量不是叶尖半径旋钮。
- 经 `scaler_X` 之后送进网络的 \(\Omega\) 已经不是 rad/s 的物理值，是标准化后的数。物理讨论仍用 rad/s；不要把标准化值当成转速。

仓库指认：预测页两个滑块，标签必须是转速与**背压**。`FEATURE_STATS` 在后端特征统计里。信里强调 P 不是进口总压，因为旧页签错过，郭老师会看页。
