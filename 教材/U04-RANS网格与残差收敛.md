# 第 4 单元 · RANS、网格与残差收敛

读完本单元，你必须能：

1. 拆开 **CFD、N-S、RANS、DNS**（还有 LES）；
2. 写出 **relrms** 的定义，并解释 −3.39 为什么**不是 3.39% 误差**、为什么叫**未收敛**；
3. 说出 **null** 是「空着还没填」，不是 0、不是考了 0 分——决策指标现在全是它；
4. 在说话时分清：本章「收敛」**只指**离散方程的残差降到事先定的阈值，不是 U08 的蒙特卡洛收敛，也不是 U09 的覆盖率校准。

**桥（不需要重学）：** U01（CFD/RANS/SU2 的名字、代理、留出集）、U03（激波、附面层、分离、熵）；高中：守恒（质量守恒、能量守恒）、速度、压强、密度。

**本章依赖链：**


## 4.1 CFD 与 RANS：在格子上解平均场

**本节依赖链：** 守恒 → N-S → 湍流尺度 → DNS → LES → RANS（时间平均 → 雷诺应力 → 封闭 → 湍流模型 SA / k-ω SST）→ SU2。

### 4.1.1 拆词

| 中文 | 英文/符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| 守恒方程 | conservation laws | 质量、动量、能量不凭空产生消失，写成方程（高中物理的守恒思想） | 进多少质量 = 出多少质量 |
| N-S 方程 | Navier–Stokes equations | 描述流体流动的**一组**方程：质量守恒 + 动量守恒 + 能量守恒，加上「牛顿流体」的粘性关系 | — |
| 湍流 | turbulence | 流动里的乱涡：不同大小、不断变化的涡 | 拧开水龙头开到最大看到的花乱流动 |
| 涡尺度 | eddy scale | 涡的大小。湍流里从大涡到极小涡都有，小的耗散成热 |
| DNS | Direct Numerical Simulation | 直接解所有湍流尺度。**对这个转子工程上太贵** |
| LES | Large Eddy Simulation | 大涡直接解、小涡用模型。比 RANS 贵、比 DNS 便宜 |
| RANS | Reynolds-Averaged Navier–Stokes | 对 N-S 做**时间平均**，脉动收进「雷诺应力」，再用湍流模型**封闭** | PLAID 标签和我们要跑的 SU2 都是这一档 |
| 雷诺应力 | Reynolds stress | 平均之后多出来的、代表**脉动输运**的项。未知 → 所以方程不封闭 → 要模型 |
| 封闭 | closure | 用模型把未知的雷诺应力写成可算的量。常见 SA、\\(k\\)-ω SST |
| SA | Spalart–Allmaras | **一个方程**的湍流模型（用一个附加方程算湍流量） |
| \\(k\\)-ω SST | k–omega SST | **两个方程**的湍流模型，航空航天 CFD 常用 |
| SU2 | Stanford University Unstructured | 开源 CFD 软件（U01 名字，这里落位）。**不是 SUR** |

**拆词：R 是 Reynolds（雷诺，人名），A 是 Averaged（平均），S 还是 Navier–Stokes 的 S。** 平均的是**时间**，不是空间：把每个时刻的乱流动按时间平均，得到「平均场」。平均之后动量方程里多出一项（雷诺应力）——它代表乱涡把动量搬来搬去的效果，是个未知量，所以方程**不封闭**，必须补一个湍流模型把它算出来。这就是「封闭」。

**操作。** 连续的气体被切成很多小格子。每个格子上写离散后的守恒式，用计算机迭代，直到左右两边差不多平衡——这就是 CFD。本项目**没有**自己产出可用的收敛 RANS 标签：约 1000 组真值来自 PLAID 别人的 RANS；我们的 SU2 是后来补的求解器通路：脚本在，粗网格跑过，细网格没跑完（4.2 说规模）。

**边界。** 「我们用 PINN 解了 N-S」是错的——PINN 要把方程残差写进神经网络损失（U06 拆），本项目训练损失里没有这件事；SU2 才是求解器，而且还没收敛。RANS 给出的是平均场，不是每一瞬间的涡；激波在平均场里通常还在，但非定常抖动可能被抹掉。

## 4.2 网格：切多细、用几阶格式

**本节依赖链：** 节点 → 单元 → 粗/细网格 → 离散格式（一阶迎风 / 二阶）→ 截断误差 / 耗散 → 非流形边 / 负体积 → 点云 2048（另一套离散）。

### 4.2.1 拆词与数字

| 中文 | 英文 | 一句定义 | 数字例子 |
|---|---|---|---|
| 节点 | node | 格子的顶点 | 本数据集叶片表面大约 **29,773** 个 |
| 单元 | cell | 由节点围成的小体积或小面。求解器在单元上积分 | 粗网格约 14 万单元 |
| 粗网格 / 细网格 | coarse / fine | 格子稀 / 密。细的截断误差小、更贵 | 14 万 / 约 355 万 |
| 截断误差 | truncation error | 把连续方程写成格子上的近似式时**砍掉的误差**。网格越细、格式阶越高，它越小 |
| 一阶迎风 | first-order upwind | 耗散大的一阶离散格式：激波和剪切层会被**抹宽** |
| 二阶格式 | second-order scheme | 耗散更小；激波处容易**振荡**，需要限制器压住 |
| 耗散 | dissipation | 数值上把「尖的东西」抹糊的效应。激波被抹宽 = 损失被抹掉或被假造 |
| 非流形边 | non-manifold edge | 几何坏了的一种症状（一条边被多于两个面共用之类）。**0 条只说明几何检查过，不说明流场收敛** |
| 负体积 | negative volume | 单元翻折了。求解器会垮或吐假场 |
| 点云 | point cloud | 一堆带坐标的散点。本项目另有一套 **2048 点**的下采样，和表面 29773 **不是同一离散** |
| HPC | High Performance Computing | 高性能计算（超算/集群）。宪章（`docs/AGENT_CHARTER.md` 第 9 条）规定：**未批准不得买算力**——细网格收敛 RANS 留给批准后的 HPC |

**本项目网格现状（三个数记死）：**

| 本项目 | 规模 | 格式意图 | 结果 |
|---|---|---|---|
| 粗 | 约 14 万单元 | 一阶迎风 | \\(\\mathrm{relrms}=-3.39\\)，`converged=false` |
| 细 | 约 355 万（审计约 3,557,497 节点量级） | 二阶意图 | 本机内存不够，没跑完。**不是闭环** |

**尺度算例。** 三维网格每个方向尺度减半，单元数大约 ×8（2³）。14 万对 355 万，线性尺度大约差 \\((355/14)^{1/3}\\approx 2.9\\) 倍——细网格在三个方向都细约 3 倍，所以贵一个数量级。

**边界。** 只能跑粗网格时，只许报「粗、一阶、未收敛」的**趋势**，不许填决策指标（4.3），不许说验证完了。一阶迎风的耗散会抹宽激波——**损失可以被抹掉，也可以被假造**，所以一阶结果连趋势都要小心说。

## 4.3 残差收敛：−3.39 在梯子的哪一格

**本节依赖链：** 迭代 → 残差 → relrms 公式（带算例）→ 平台 / 发散 → 未收敛 → null → 决策指标必须空着 → 三种收敛对照表。

### 4.3.1 拆词与公式

| 中文 | 英文/符号 | 一句定义 |
|---|---|---|
| 迭代 | iteration | 猜一个解 → 算方程两边差多少 → 改一点 → 再算……一步步逼近 |
| 残差 | residual \\(\\mathbf{R}\\) | 离散方程**左右两边还差多少**（第 k 步的不平衡量） |
| relrms | relative RMS | 相对残差：见公式。相对的是**初始残差** |
| 平台 | stall / hang | 残差掉不动了，曲线走平 |
| 发散 | diverge | 残差往上走，越算越糟 |
| 收敛判据 | convergence criterion | 事先定的门槛：残差够小 + 进出口流量守恒 + \\(\\pi,\\eta,\\dot m\\) 稳住 |
| null | null | 这里**空着、还没有填数**。不是 0，也不是考了 0 分 |
| 决策指标 | decision metrics | Spearman、Top-k 等（U07 才拆）。**没有收敛 RANS 对照前必须保持 null** |

\\[
\\mathrm{relrms}=\\log_{10}\\frac{\\|\\mathbf{R}^{(k)}\\|}{\\|\\mathbf{R}^{(0)}\\|}
\\]

\\(\\mathbf{R}^{(0)}\\) 是第一步的残差，\\(\\mathbf{R}^{(k)}\\) 是第 k 步的。

**算例：** −3.39 的意思是

\\[
10^{-3.39}\\approx 4\\times10^{-4}
\\]

残差变成初始的约万分之四。工程上常希望到 **−6**（再掉约 2.6 个数量级），并且进出口流量守恒、\\(\\pi,\\eta,\\dot m\\) 稳住。我们日志给的是**平台**：掉不动了。所以 **未收敛**。**它不是误差 3.39%**——它是对数尺上的一个位置。

**未收敛的后果。** 激波位置可以还在漂（U03：η 对激波位置极敏感），\\(\\eta\\) 可以还在晃。拿它给代理点「验一下」，得到的是随机数——不能填 Spearman。残差到了 −6 但 \\(\\eta\\) 仍震荡，也不算工程收敛。求解器启动了，更不是「E4 完成一半」：**跑过 ≠ 可用**（E 档的系统名字在 U11）。

**三种收敛（先挂名字，后两行到 U08、U09 才展开）：**

| 名字 | 在收敛的是什么 | 本项目 |
|---|---|---|
| RANS 残差 | 离散方程的不平衡 | −3.39，未收敛 |
| MC 估计量 | 抽样次数够不够 | U08，\\(T=100\\) 够稳 |
| 覆盖率校准 | 区间是否盖到名义水平 | U09，η 只有 65% |

一句话里出现两种，必须点明换了含义——**「收敛」在本章单指第一行**。

**数据。** `evidence/metrics.json`：`su2_coarse.relrms_platform = -3.39`，`converged: false`；`decision_metrics` 全部 `null`。仓库指认：同上。宪章：收敛 RANS 对照前，禁止用代理自比填决策指标。
