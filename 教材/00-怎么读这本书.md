# 怎么读这本书（先读这一页，再进 U01）

这本书的读者画像只有一个人：**高考 650 分、对大学零了解的你**。教材每一句的验收标准也只有一条：

> **逐句读完，不需要打开任何搜索。你读到一个不认识的词，是教材的问题，不是你的问题。**

读完的最终验收不变，仍是两件事：

1. 发送包十问能用自己的话答，且不越档（`docs/郭老师发送包.md` 第 5 节）。
2. 每一句对外口径能指到仓库里的一个文件或一个字段。公开数字只认 `evidence/metrics.json`。

## 你现在会的、本书直接当桥的

压力（压强）、速度、温度、密度、质量、体积、力、功（力 × 沿力的方向的位移）、位移、内能、比热容（高中 \\(Q=cm\\Delta T\\) 的 \\(c\\)）。
数学：比、百分数、导数、微分、向量、均值、标准差。

**就这些。** 马赫数、等熵、激波、附面层、RANS、残差、网格、代理模型、ONNX、留出集、\\(R^2\\)、Dropout、覆盖率、Pareto、null、E0–E4——全部在你第一次遇到它们的章节当场定义，你不需要事先知道任何一个。

## 零搜索协议（全书统一）

1. 每个新词第一次出现，当场给四件套：**中文名 / 英文或符号 / 单位 / 一个具体数字例子**。
2. 每个定义里出现的词，只允许是：桥词、本章前面已定义过的词、或写着「（U0X 才讲，这里只记名字）」的词。
3. 每一节开头先给**术语依赖链**：这一节先学什么、后学什么，顺序为什么不能反。
4. 每个重要公式后面，都跟着一个代入数字、一步步算完的例子。
5. 读到生词就停下来圈出来告诉我——那是教材违规，我来补。

## 目录为什么这样排

旧版把「证据等级」放第一章。桌上还没认全「代理 / ONNX / 留出集 / SU2 / 残差」，五档表读起来像天书。这是上一版翻车的原因。

新顺序只做一件事：先让你看见机器和三个数，再讲怎么算、怎么近似、怎么量不确定度，最后才给每句话盖档，并练郭老师那十问。

| 单元 | 读完必须能做的一件事 |
|---|---|
| U01 | 说出 π、η、ṁ 是什么，并指出冻定数在哪个文件 |
| U02 | 分清绝对/相对速度；说出 P 是背压；分清页面焓升和欧拉功 |
| U03 | 用自己的话定义激波和附面层；不把 Rotor 37 叫涡轮 |
| U04 | 解释 relrms=−3.39 为什么叫未收敛（RANS 残差收敛） |
| U05 | 把 74 维拆成 9×8+Ω+P；说明它不是可铣旋钮 |
| U06 | 画出残差块；说明损失里没有 N-S，所以不是 PINN |
| U07 | 写出 \\(R^2\\)；说明高 \\(R^2\\) 为什么仍不能说优化可靠 |
| U08 | 拆开 M / C / Dropout；说出生产端其实是常数 σ |
| U09 | 用覆盖率解释 65%；说出加宽补什么、不补什么 |
| U10 | 说明 0.9173 不是叶片；流形约 3× |
| U11 | 给一句话对档；指认 `evidence/` 与禁词 |
| U12 | 闭卷答十问，并指出三块铁证对应仓库里还缺的东西 |

## 每一章怎么读

1. 先读该章开头的**桥与依赖链**：这一章拿你会的什么当工具、新词按什么顺序学。
2. 正文逐词展开，每个新词都有四件套；公式后面跟算例，用计算器跟着按一遍。
3. 读完一节，先过「本节自检」清单；全过再做题。
4. 节末 10 题（2 选 + 2 填 + 6 问），单元卷 30 题。先做再对 `教材配套答案详解.md`。
5. 章末「仓库指认」打开真文件对一遍；数字对不上讲义，以 `evidence/metrics.json` 为准。

日历不锁两周。读卡就停在该章，把卡住的那个词圈出来；不要跳期末。
