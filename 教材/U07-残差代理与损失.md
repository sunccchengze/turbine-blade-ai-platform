# 第 7 单元 · 残差代理与损失

对象：`notebooks/04_residual_physics_model.ipynb` 里的网。约 **523,011** 参数，ONNX 约 **2.11 MB**。

---

## 7.1 代理是一个函数

**代理模型**（surrogate）：用便宜的 \(f_\theta(x)\) 近似昂贵的仿真 \(y=\mathrm{CFD}(x)\)。  
这里 \(x\in\mathbb{R}^{74}\)，\(y\in\mathbb{R}^3=(\pi,\eta,\dot m)\)。

**神经元**：一层里的一个标量。线性 \(w\cdot h+b\) 再加非线性。  
**ReLU**：\(\mathrm{ReLU}(z)=\max(z,0)\)。整网是分段线性连续函数。  
**权重**：所有 \(W,b\)。训练改它们。  
**前向**：给定 \(x\) 和当前权重，算出 \(y\)。  
**反向 / 梯度**：损失对权重的导数，Adam 沿着它走。

过拟合：训练误差远小于测试误差。本项目 train \(R^2\) 可到 0.99，测试 0.96 档，差距要诚实公开。

---

## 7.2 残差块与 Dropout（训练期）

残差块（He et al., 2016）：

\[
x \mapsto \mathrm{ReLU}\big(F(x)+x\big)
\]

\(F\) 里：Linear → BN → ReLU → Dropout(0.1) → Linear → BN。  
捷径让梯度能抄近路；最差 \(F\approx 0\)，块退化成恒等。

整网：

```
74 → 256 + BN + ReLU + Dropout(0.1)
   → ResidualBlock ×3 (256)
   → 128 + BN + ReLU + Dropout(0.1)
   → ResidualBlock ×2 (128)
   → 3
```

**Dropout（训练）**：每个激活以 \(p=0.1\) 乘 0，留下的除以 \(0.9\)。这是正则，逼网络不要只靠某几个神经元。推理默认关掉（`eval()`）。MC Dropout 是以后故意不关，见 U09。

BatchNorm：用当前 batch 的均值方差标准化，再学缩放平移。训练和推理统计量不同，和 Dropout 一起开着做 MC 时会有争议——知道有此事即可。

---

## 7.3 损失：加权 MSE + 边界惩罚，不是 PINN

\[
L=\sum_{i\in\{\pi,\eta,\dot m\}} w_i\,\mathrm{MSE}_i +\lambda\sum_j \big(\mathrm{ReLU}(g_j)\big)^2
\]

\(w=(1,3,1.5)\)，\(\lambda=0.1\)。\(g_j\) 是越界量：\(\eta>1\)、\(\eta<0.5\)、\(\pi<1\)、\(\dot m<0\)。

**PINN**：把微分方程残差（例如 N-S）加进损失，在配点上罚 \(\|\mathcal{N}[u]\|\)。  
本项目**没有**在配点上算 N-S。ReLU² 只是把输出按进盒子。信里必须说「不是 PINN」。

优化器 Adam，lr \(10^{-3}\)，weight decay \(10^{-4}\)，余弦退火，早停耐心 40。这些是训练超参，不是物理。
