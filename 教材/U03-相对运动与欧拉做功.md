# 第 3 单元 · 相对运动与欧拉做功

预测页有转速 \(\Omega\)（rad/s）和一格「滞止焓升」。要读懂它们，必须先站到**跟着叶片一起转**的坐标系里。

---

## 3.1 画面：绝对速度、牵连速度、相对速度

叶片以角速度 \(\Omega\) 旋转。半径 \(r\) 处，固体本身的线速度（牵连速度）

\[
U=\Omega r
\]

气的**绝对速度** \(\mathbf{C}\)（实验室/机匣看）、**相对速度** \(\mathbf{W}\)（站在叶片上看）满足

\[
\mathbf{C}=\mathbf{W}+\mathbf{U}
\]

向量三角形：进口画一次，出口再画一次，这就是级的速度三角形。

**相对马赫数**

\[
M_\mathrm{rel}=\frac{|\mathbf{W}|}{a},\quad a=\sqrt{\gamma R T}
\]

\(a\) 是当地声速。Rotor 37 **叶尖**公开设计值大约 \(M_\mathrm{rel}\approx 1.48\)：叶尖相对来流已经超音速。这是文献/基准的典型数，不是我们 SU2 跑出来的 E4。

超音速相对来流 → 通道里可以立激波（U04）。\(\Omega\) 越大，同样半径上 \(U\) 越大，\(M_\mathrm{rel}\) 越高，激波越强——所以滑块上的转速不是「转得欢就三项一起好」。

本项目 \(\Omega\) 的数据范围大约 1620–1800 rad/s（设计转速量级约 17188.7 rpm，见 data card）。单位是 **rad/s**，曾经有人标成 rpm，差 \(2\pi/60\approx 9.55\) 倍，那是错的。

---

## 3.2 公式：欧拉做功方程

对轴流级，单位质量的理论滞止焓升（欧拉方程，忽略径向掺混的最简形式）

\[
\Delta h_0 = U_2 C_{\theta 2}-U_1 C_{\theta 1}
\]

\(C_\theta\) 是绝对速度的周向分量。进口若预旋很小，\(C_{\theta 1}\approx 0\)，则 \(\Delta h_0\approx U_2 C_{\theta 2}\)。  
物理：叶片给气一个周向动量，气的滞止焓就升高。这是**做功**，不是摩擦生热。

它和等熵焓升不是同一个量：

| | 欧拉 \(\Delta h_0\) | 页面上那格 \(\Delta h_0\) |
|---|---|---|
| 来源 | 速度三角形 / 动量矩 | \(c_p T_{t1}(\pi^{(\gamma-1)/\gamma}-1)\) |
| 是什么 | 实际做功（理想化、无损失形式是理论功） | **等熵**过程达到同一 \(\pi\) 所需的焓升 |
| 在本仓库 | **没有**作为网络输出，也没有进损失 | 前端用预测 \(\pi\) 现场算的参考 |

「我接了欧拉做功」若让人听成「网络里嵌了欧拉方程」，就越档。第 4 稿的信已经改成：页面参考；网络只有边界惩罚。

---

## 3.3 操作：两个工况旋钮

74 维里真正的**工况**只有两个，不是从三万个点算出来的：

- \(\Omega\)：转速  
- \(P\)：**背压**（出口静压，用来节流）。不是进口总压。旧页面标错过。

压气机特性通常画成：横轴 \(\dot m\)（或修正流量），纵轴 \(\pi\)，不同转速一条线；背压变化就是沿一条转速线移动。背压升高 → 通常流量下降，靠近失速边；背压降低 → 流量上升，靠近堵塞边。

代理只在训练时见过的 \(\Omega,P\) 范围内插值。超出 `FEATURE_STATS` 应 422 拒绝。这是 abstain 的雏形，不是「模型什么都能外推」。

**边界**

- 没有进口总温、进口总压作为独立标签去扫全特性（所以不能说全工况）。  
- \(U=\Omega r\) 需要半径。74 维里有 Coordinate 的统计量，但那不是「叶尖半径」这个设计旋钮。  
- 欧拉方程要的是进出口周向速度，统计特征里**没有** \(C_\theta\) 场。网络不可能「内部在用欧拉方程」，它只见过统计量。
