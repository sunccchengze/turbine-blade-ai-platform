# 第 5 单元 · 从三万点到 74 维

读完本单元，你必须能：

1. 把 74 拆成 **9×8 + Ω + P**，并说出八个数里是 **std（标准差）不是方差**；
2. 说明这是**多对一**映射：激波位置在「核」里被捏没了；
3. 回答「你的设计变量是什么」——**现在不是**：74 维是场统计；**下一步才是 CST/FFD**（名字）；

**桥（不需要重学）：** U01（代理、特征名字、留出集）、U03（激波位置）、U04（表面节点 29773、null）；高中：均值、标准差、分布。

**本章依赖链：**


## 5.1 画面：三万个点上有一张场，不是 74 个旋钮

**本节依赖链：** 场量 → 9 个场 → 拉直 → 维数灾难 → 必须约化 → 点云 2048（另一套）。

### 5.1.1 拆词

| 中文 | 英文/符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| 表面节点 | surface node（U04 复习） | 叶片表面上的离散点 | 本数据集大约 **29,773** 个 |
| 场量 | field variable | 每个节点上的一个数。本章 9 个：坐标 3、法向 3、压/密/温 3 | 见下表 |
| 坐标 | coordinate | 该节点的空间位置分量：CoordinateX、CoordinateY、CoordinateZ | 3 个场 |
| 法向 | normal | 表面朝外的**单位方向**，三个分量 NormalsX/Y/Z。它描述**朝向**，不是厚度旋钮 | 3 个场 |
| 维数灾难 | curse of dimensionality | 维数升高时，空间体积爆炸式膨胀，样本点填不满 | 1000 个样本填不满 \\(2.7\\times10^5\\) 维 |

**九组场（把每个样本的表面画成一张表）：**

| 组 | 分量 | 说的是什么 |
|---|---|---|
| 几何-坐标 | CoordinateX, CoordinateY, CoordinateZ | 每个点在哪 |
| 几何-法向 | NormalsX, NormalsY, NormalsZ | 每个点处表面朝哪 |
| 流场 | Pressure, Density, Temperature | 每个点处压力 / 密度 / 温度 |

**算例。** 若把 \\(29773\\times 9\\) 拉直成一串，约 \\(2.7\\times10^5\\) 维（26.8 万），样本只有约 1000。维数这么高，点与点之间的距离失去分辨力——这就是**维数灾难**，所以必须**约化**（把高维信息压缩成少数几个数）。

**边界。** 点云 2048 是另一套下采样，和表面 29773 **不是同一离散**（U04 已钉）。坐标均值不是叶尖半径，不能当设计变量；法向描述朝向，不能可靠恢复弯扭（弯扭 = 叶片沿叶高的弯曲和扭转，名字先记）。

## 5.2 操作：九场 × 八统计 + 两个工况

**本节依赖链：** 8 个统计量逐个定义 → 9×8=72 → +Ω+P=74 → 多对一 → 核 → 偏度 ≠ 位置 → 标准化（名字复习）。

### 5.2.1 八个统计量逐个钉死（高中已会均值/标准差，其余新）

| 统计量 | 中文 | 一句话定义 | 注意 |
|---|---|---|---|
| mean | 均值 | 全部数加起来除以个数 | 高中就会 |
| **std** | **标准差** | 数们围着均值散多开的标准尺 | **不是方差**。方差 = std² |
| min, max | 最小、最大 | 全部数里最小的、最大的 | |
| p25, p75 | 第一、第三四分位 | 从小到大排：p25 = 25% 位置处的数；p75 = 75% 位置处 | 中位数是 p50 |
| skew | 偏度 | 分布左右偏的**一个数**：正 = 尾巴往右 | 它**不是**「激波在 70% 叶高」 |
| kurt | 峰度 | 分布尾巴胖瘦的一个数 | |

**74 的拆法：** \\(9\\times 8=72\\)，加上工况 \\(\\Omega,P\\)（U02 已定义：转速与背压）得 **74**。\\(\\Omega,P\\) 不是从三万点算出来的——它们是实验台旋钮。

**拆词：核（kernel）。** 从「三万点的场」到「74 个数」是**多对一**映射：很多不同的场被映成同一个 74 维向量。被映成同一个 \\(x\\) 的所有场，构成这个映射的**核**。

**关键后果（本章的题眼）。** 激波偏前、偏后，Pressure 的 mean 和 skew 可以**几乎一样**——激波位置在核里，被捏没了。偏度算完就留下一个标量（一个孤零零的数），**不会发回三万个点**：「把偏度发回每个节点就能看见激波」是错的——偏度已经没有空间下标。

**数据。** `sample_id`（样本编号）不算 74 维之一。标准化（U02 名字，U06 拆）只改数值尺度，不改物理定义。Pressure_std 大，除了激波强，**叶尖泄漏、端壁二次流**也会抬它——所以单看 std 不能断定是激波。

## 5.3 为什么这不是 CST / FFD

**本节依赖链：** 设计变量 → CST / FFD / B 样条 / 前缘半径（名字）→ 74 维不可逆 → 三维预览是示意 → 官方 test 200 → 融合 R² 未冻结 → C06。

### 5.3.1 拆词

| 中文/名字 | 一句定义 |
|---|---|
| 设计变量 | 能生成**合法几何**、能进网格和求解器的参数。例如 CST 权重、FFD 控制点、B 样条、前缘半径、厚度 |
| CST | Class Shape Transformation，用一组系数生成光滑叶型的参数化方法（**名字，U12 才展开**） |
| FFD | Free-Form Deformation，自由变形：动几个控制点，把几何整体捏变（**名字**） |
| B 样条 | B-spline，用控制点定义的数学曲线（**名字**） |
| 前缘半径 / 厚度 | 叶片最前端圆角的半径 / 叶片薄厚——铣床（加工叶片的机床）听得懂的几何量 |
| 逆映射 / 反解 | 从 74 维**还原出**一片几何。**本项目没有** |

**操作对比（一句话记住）。** Pressure_skew 是**流场统计**，铣床听不懂。在这 74 维里搜，得到另一个 74 维向量，**不保证存在**一片叶子实现它——盒子内可能没有可网格化原像（原像 = 能被映成这个向量的那片几何）。三维预览是**示意重构**，不是逆映射 CAD。

**官方 test 200 组：** 几何和标签隐藏、只给工况，算不出 \\(R^2\\)（U01 已钉）。本项目 \\(R^2\\) 是随机留出 100 点（U07 详讲划分），**不是跨几何族泛化**——随机抽同分布的点，和「换一族新叶子还能不能行」是两回事。

**融合 R² 区间未多种子复现**，列在 `do_not_freeze`（「不许冻结」清单，U11 详讲），不能当课题结论。PointNet / GNN（名字：直接在点坐标上做卷积/消息传递的网络，能保留空间信息）是另一条路线，本项目只做了融合尝试。

**C06（对外可写条目，`evidence/claims.yaml`）：** 74 维是表面统计量，不是可设计几何。
