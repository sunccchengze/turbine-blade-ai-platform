# 第 6 单元 · 从三万点到 74 维

本单元钉死学长和 Q1 的那句话：**74 维是全局统计约化，不是可加工的几何旋钮。**

---

## 6.1 画面：三万个节点上有什么

每个 PLAID 样本，叶片表面大约 29,773 个节点。每个节点 9 个场量：

CoordinateX, Y, Z；NormalsX, Y, Z；Pressure, Density, Temperature。

这是一张离散的表面场，不是 74 个旋钮。若直接把 \(29773\times 9\) 个数拉直，维数约 \(2.7\times 10^5\)，样本只有 1000，必崩——这叫**维数灾难**（curse of dimensionality）：维度升高，体积指数膨胀，点与点的距离变得没有分辨力。

---

## 6.2 操作：九场 × 八统计 + 两个工况

对每一组场，在全部表面节点上算 8 个数：

| 统计量 | 符号/名字 | 注意 |
|---|---|---|
| mean | 均值 | |
| **std** | **标准差** | 不是方差。方差是 \(\mathrm{std}^2\) |
| min, max | 最小、最大 | |
| p25, p75 | 第一、第三四分位 | |
| skew | 偏度 | 分布左偏右偏的一个数，**不是**「激波在 70% 叶高」 |
| kurt | 峰度 | 尾巴胖瘦的一个数 |

\(9\times 8=72\)，加上 \(\Omega,P\) 得 **74**。  
\(\Omega,P\) 不是从三万点算出来的，是算例的工况。

这是多对一映射：激波偏前、偏后，Pressure_mean 和 Pressure_skew 可以几乎一样。位置信息在这个映射的**核**里——被捏没了。

偏度/峰度算完就留下两个标量，**不会**发回三万个点。

---

## 6.3 为什么这不是 CST / FFD

**设计变量**（design variable）：能生成合法几何、能进网格和求解器的参数。例如 CST 的权重、FFD 控制点、B 样条控制点、前缘半径、厚度。

74 维里的 Pressure_skew 是流场的统计，铣床听不懂。NSGA-II 在这 74 维里搜，得到的是另一个 74 维向量，**不保证存在**一片叶子实现它，更不保证那片叶子合法、可加工。

三维预览是示意重构，不是这个向量的逆映射。

官方 test 200 组：几何和标签隐藏，只给工况。所以官方 test 上算不出 \(R^2\)。本项目 \(R^2\) 是随机留出 100 点，不是跨几何族泛化证明。
