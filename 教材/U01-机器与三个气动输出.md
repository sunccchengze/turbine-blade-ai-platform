## 1.1 画面：一级在干什么

![轴流级与三个输出](figures/U01-stage-three-outputs.svg)

先认词（本节用到的，全部在这里钉死）：

| 中文 | 英文 | 一句操作定义 |
|---|---|---|
| 压气机 | compressor | 把空气压得更紧、送去后面用的叶轮机械。本项目只研究其中一排转子，不是整台发动机 |
| 级 | stage | 通常 = 一排转子 + 一排静子。本项目对象只有转子这一排 |
| 转子 | rotor | 跟着轴转的那排叶片，对气体做功 |
| 静子 | stator | 不转的那排叶片，把动能收回静压。本数据集标签不是单独的静子性能 |
| 跨音速 | transonic | 同一流场里既有亚音速区也有超音速区 |
| 马赫数 | Mach number \(M\) | 当地流速除以当地声速。\(M<1\) 亚音，\(M>1\) 超音 |
| 声速 | speed of sound \(a\) | 小扰动在该气体里传播的速度。完全气体常用 \(a=\sqrt{\gamma RT}\)，\(T\) 是当地静温 |
| NASA Rotor 37 | NASA Rotor 37 | 公开的跨音速压气机转子基准件，用来验方法和 CFD，不是涡轮，不是涡扇整机 |

轴流压气机由很多级串起来。气沿轴线走，转子给它周向动量，压强和温度升高。工程师至少要三个数，才知道「这一级干得怎么样」：压得猛不猛、浪费少不少、每秒过多少气。下一节把这三个数写成符号。

**Rotor 37 不是谁。** 它不是涡轮叶片（涡轮是燃气膨胀做功，压气机是耗功把气压上去）。它不是风扇整级，不是涡扇。KIT 无压气机氢燃机跑 303 秒是行业引子，不是本项目算的那片叶子。

仓库指认：对象写在 `data_card.md` 与 `docs/CLAIM_EVIDENCE.md`。对外说话把 Rotor 37 叫涡轮，直接违规。

## 1.2 拆词与公式：π、η、ṁ

先认词：

| 中文 | 符号 | 一句操作定义 |
|---|---|---|
| 静压 | \(p\) | 跟气流一起走的人测到的热力学压力，单位 Pa |
| 总压 / 滞止压 | \(p_t\) | 把气等熵地刹到静止时的压力。它包含静压和速度头 |
| 总压比 | \(\pi\) | 出口总压除以进口总压。本项目字段 `Compression_ratio` |
| 焓 | \(h\) | 单位质量的 \(u+p/\rho\)。压气机关心的是滞止焓怎么升 |
| 等熵 | isentropic | 可逆且与外界无热量交换。对压气机：同样压比，等熵过程耗功最少 |
| 等熵效率（总对总） | \(\eta\) 或 \(\eta_{tt}\) | 等熵滞止焓升除以实际滞止焓升。本项目字段 `Efficiency` |
| 质量流量 | \(\dot m\) | 每秒穿过选定截面的质量，单位 kg/s。本项目字段 `Massflow` |
| 比热比 | \(\gamma\) | \(c_p/c_v\)。空气常取 1.4，于是 \((\gamma-1)/\gamma=0.2857\) |

**总压的思想实验。** 把一股气沿流线等熵地刹停，压力升到的那个值叫总压 \(p_t\)。静压是当地的热力学压力。压气机性能上用的是总压比，不是随便一个壁面静压比。

进口总压 \(p_{t1}\)，出口总压 \(p_{t2}\)：

\[
\pi=\frac{p_{t2}}{p_{t1}}
\]

\(\pi>1\) 才是在压缩。\(\pi=2.1\) 的意思：出口总压大约是进口总压的 2.1 倍。

对量热完全气体，等熵关系 \(p_t\sim T_t^{\gamma/(\gamma-1)}\)。压气机总对总等熵效率一种常用写法：

\[
\eta_{tt}=\frac{\pi^{(\gamma-1)/\gamma}-1}{T_{t2}/T_{t1}-1}
\]

分子是「同样压比、若过程等熵」该有的温升（写成无量纲）。分母是实际总温比减 1。实际有激波、分离、掺混，分母更大，所以 \(\eta<1\)。热力学第二定律禁止 \(\eta>1\)。这就是后面损失里 \(\eta\le 1\) 惩罚的来源——它是输出边界，不是把熵方程写进网络。

质量流量：

\[
\dot m=\int_{\text{截面}}\rho\,\mathbf{u}\cdot\mathbf{n}\,dA
\]

\(\rho\) 密度，\(\mathbf{u}\) 速度，\(\mathbf{n}\) 截面外法向。堵塞（choke）：喉部到声速后再降背压，\(\dot m\) 几乎不再增加。Rotor 37 公开叙事里，流量顶到约 21.74 kg/s 附近就是这个边。那边 \(\eta\) 会掉。原因（激波–附面层）在 U03 讲。

本项目数据里 \(\eta\) 只在大约 **0.045** 宽的窄带里变。所以它难拟合。训练时这一路损失权重是 **3**（压比 1，流量 1.5）。权重是超参数，不是定律。

仓库指认：三个字段在特征表 `data/processed/plaid_rotor37_features.csv` 的输出列，也在预测页三张卡片上。

## 1.3 操作：这些数在本仓库里怎么出现

先认词（本节新出现的）：

| 中文 | 英文 | 一句操作定义 |
|---|---|---|
| 代理模型 | surrogate | 用已经算过的贵仿真当老师，训出一个便宜的输入→输出函数，用来代替再跑一次贵仿真 |
| 标签 | label | 老师给的标准答案。这里是别人 RANS 算出的 \(\pi,\eta,\dot m\)，不是我们 SU2 算的 |
| PLAID | PLAID | 公开数据集名。带标签大约 1000 组；另有官方 test 200 组标签隐藏 |
| 留出集 | holdout | 训练时完全没见过、专门用来打分的样本。本项目 \(n=100\)，`random_state=42` |
| \(R^2\) | coefficient of determination | 1 −（预测残差平方和）/（相对均值的总变差）。1 完美，0 和猜均值一样糟。公式在 U07 展开 |
| ONNX | Open Neural Network Exchange | 把训好的网络存成一种别人不用原训练框架也能算的文件格式 |
| 求解器 | solver | 在电脑上迭代解离散方程的程序。本项目后来补的通路是 SU2 |
| SU2 | Stanford University Unstructured | 开源 CFD 软件。不是 SUR |

操作四步：

1. PLAID 对每个样本给了三个标量标签（来自**人家的** RANS）。
2. 特征工程之后写入 CSV 的三列。
3. 网络输出三维向量，经 `scaler_y_v2` 反标准化，变回原来的量纲。
4. 网页 `/predict` 三张卡片就是这三列。

冻住的留出集 \(R^2\)（这是后文的 E2，档的名字 U11 才系统讲；现在只要记住：这是代理对留出集的拟合，不是收敛 CFD）：

\[
R^2_\pi=0.9844,\quad R^2_\eta=0.9561,\quad R^2_{\dot m}=0.9827
\]

基线 MLP：0.9664 / 0.9132 / 0.9492。\(\eta\) 仍然最差。

代理搜索到的端点（仍是代理吐的数，不是叶子）：

- \(\eta_{\max}=0.9173097\)，训练均值 \(\langle\eta\rangle=0.8703\)，相对 +5.4%
- \(\dot m_{\max}=21.7379\,\mathrm{kg/s}\)，该点 \(\eta\approx 0.873\)
- \(\pi_{\max}=2.1073413\)

约束：\(\pi\ge 1.8\)，\(\eta\ge 0.84\)。

预测页上那格「滞止焓升」用的是

\[
\Delta h_0\approx c_p T_{t1}(\pi^{0.2857}-1),\quad c_p=1.005\,\mathrm{kJ/(kg\cdot K)},\ T_{t1}=288.15\,\mathrm{K}
\]

这是**等熵焓升的估计**，拿预测出来的 \(\pi\) 代入，当页面参考。它不是网络的一个输出头，不是欧拉方程被写进损失，进口总温还被冻在 288.15 K。

**边界。** 三个输出都是气动标量。没有应力、温度场约束、寿命、加工公差，所以现在不能叫多学科设计优化（MDO，U12 再拆）。标签来自别人的 RANS；我们自己的 SU2 还没收敛（U04 才讲残差）。所以三个数的「真」是相对 PLAID 标签的真，不是我们物理闭环核过的真。

仓库指认：

```text

backend/models/surrogate_model.onnx  训好的代理文件，约 2.11 MB
data/processed/pareto_front_solutions.csv  代理非支配点
```
