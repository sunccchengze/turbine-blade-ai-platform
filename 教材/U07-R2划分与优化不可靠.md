# 第 7 单元 · R²、划分与「优化不可靠」

Q2 的正课。\(R^2=0.98\) 仍然不能说优化可靠。

---

先认词（本章新出现的）：

| 中文 | 英文 | 一句操作定义 |
|---|---|---|
| \(R^2\) | coefficient of determination | \(1-\mathrm{SS}_{res}/\mathrm{SS}_{tot}\)。量的是平均拟合，不是排序 |
| MAE | mean absolute error | \(\frac1n\sum\|y-\hat y\|\)，带原单位 |
| 随机留出 | random holdout | 随机抽一部分当测试。本项目 800/100/100，seed=42 |
| 流形距离 3× | manifold 3× | Pareto 到训练集最近邻中位距离约 17.4，训练集内部约 6.1 |
| 决策指标 | decision metrics | Spearman、Top-k Recall 等。无收敛 RANS 前必须保持 null |
| 超体积 HV | hypervolume | 前沿围出的体积。本页曾出现假 HV，已改成破折号 |

仓库指认：`evidence/metrics.json` 的 `split`、`surrogate_holdout.r2`、`decision_metrics`（全 null）。


## 7.1 \(R^2\) 量的是什么

\[
R^2=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y)^2}
\]

分子：预测残差平方和。分母：相对均值的总变差。  
\(R^2=1\) 完美拟合；\(R^2=0\) 和猜均值一样糟；可以是负的。

它是**平均拟合**。100 个点里 95 个极准、5 个在流形边上炸，平均仍可很高。优化偏偏爱往边上走。

MAE：\(\frac1n\sum|y-\hat y|\)，带原单位。\(\eta\) 的 MAE 约 \(10^{-3}\) 量级（页上曾写 0.0031 一类，以复现脚本为准）。

---

## 7.2 划分

本项目：`train_test_split`，800 / 100 / 100，seed=42。这是**随机留出**，工程开发划分。

不是：

- PLAID 官方 test 200（标签隐藏）  
- 按几何家族、按叶尖马赫、按近堵塞 / 近失速分层  
- 多种子平均

所以：\(R^2\) 证明「在同分布随机抽的 100 点上拟合好」，不证明「换一族叶子还好」，更不证明「Pareto 边上还好」。

训练集内部最近邻中位距离约 6.1（标准化空间），Pareto 到训练集最近邻约 17.4，约 **3×**。前沿在流形边缘，+5.4% 更像外推。

---

## 7.3 排序错了会怎样

优化要的不是平均 \(R^2\)，是**排序**：谁该进 Top-k 去跑贵的 RANS。

学长点名、现在全是 null 的决策指标：

| 指标 | 问的是 |
|---|---|
| Spearman / Kendall | 代理排序和 CFD 排序是否同调 |
| Top-k Recall | 真前 k 里有几个被模型前 k 抓住 |
| Feasibility Precision | 说可行的有多少真可行 |
| Pareto HV Error | 代理前沿相对 CFD 前沿的超体积误差 |
| Optimization Regret | 按代理选的点，CFD 上后悔多少 |
| CFD Budget Saved | 相对随机/全算，省了多少次真计算 |

没有收敛 RANS 对照，用代理自己和自己比来填这些数，叫做伪造。优化页上曾经出现过随代数线性涨的假 HV，已经改成破折号。
