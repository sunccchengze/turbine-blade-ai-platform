# 第 7 单元 · R²、划分与「优化不可靠」

离开本单元，你必须能：写出 R^2=1-SS_res/SS_tot 并说出它量的是平均拟合不是排序；报出划分 800/100/100 seed=42；说出流形约 17.4 vs 6.1（3×）；列出决策指标现在全是 null 的原因。

Q2 正课：R^2=0.98 仍然不能说优化可靠。

---

## 7.1 R^2 量的是平均拟合

先认词：

| 中文 | 符号 | 一句操作定义 |
|---|---|---|
| R^2 | coefficient of determination | 1-Σ(y-ŷ)^2/Σ(y-ȳ)^2。1 完美，0 和猜均值一样糟，可以为负 |
| MAE | mean absolute error | 1/nΣ‖y-ŷ‖，带原单位 |
| SS_res | 残差平方和 | 预测错了多少 |
| SS_tot | 总变差 | 相对均值散开多少。η 窄带让分母很小 |

**画面。** 100 个点里 95 个极准、5 个在边上炸，平均 R^2 仍可很高。优化偏偏爱往边上走。

**公式。** 冻住 holdout：π 0.9844 / η 0.9561 / ṁ 0.9827。η 分母小，一点误差就砸 R^2，所以它对误差更敏感，不是更钝。训练 0.99 / 测试 0.96 是过拟合迹象，要诚实公开。

MAE 带原单位。η 的 MAE 约 10^(-3) 量级，以复现脚本为准。

**边界。** 拟合好和排序对不是一回事。单调变换可以几乎不改 R^2 却换掉 Top-1，也可以反过来。

---

## 7.2 划分：随机留出证明什么、不证明什么

本项目 `train_test_split`：800 / 100 / 100，seed=42。这是工程开发划分，同分布随机抽。

不是：PLAID 官方 test 200（标签隐藏，算不出 R^2）；按几何家族 / 叶尖马赫 / 近堵塞分层；多种子平均。

所以 R^2 只证明「在同分布随机 100 点上拟合好」，不证明换一族叶子还好，更不证明 Pareto 边上还好。Level 1 的多种子没做。

val 用来早停和调参；test 只许终评一次。测试集参与早停叫泄漏。早停看 val，不看 test。

**流形 3×。** 标准化空间里，训练集内部最近邻中位距离约 6.1，Pareto 到训练集最近邻约 17.4，约 3×。+5.4% 更像外推。口误「流初级」= 留出集。

仓库指认：`evidence/metrics.json` → `split`、`nsga2_surrogate.manifold_note`。

## 7.3 排序错了会怎样；决策指标为什么是 null

优化要的不是平均 R^2，是**谁该进 Top-k 去跑贵的 RANS**。

| 指标 | 问的是 |
|---|---|
| Spearman / Kendall | 代理排序和 CFD 排序是否同调（用的是秩，不是原值） |
| Top-k Recall | 真前 k 里有几个被模型前 k 抓住。Top-5 分母是 5 |
| Feasibility Precision | 说可行的有多少真可行。没有几何合法性定义时很难算 |
| Pareto HV Error | 代理前沿相对 CFD 前沿的超体积误差 |
| Optimization Regret | 按代理选的点，CFD 上后悔多少。必须用 CFD 定义 |
| CFD Budget Saved | 相对随机/全算，省了多少次真计算 |

没有收敛 RANS 对照，用代理自己和自己比来填这些数，叫做伪造。优化页曾经出现随代数线性涨的假 HV，已改成破折号。

邻域 MAE 持平只能说「边上拟合未明显恶化」，不能代替 Spearman。

第一轮若只核 8 个点（高η低σ / 高η高σ / 对照），只能填很糙的 Spearman/Top-k；HV 与 Budget 仍空。

郭老师先问排序，因为他关心少算几次真 CFD，不关心再要一个平均 R^2。
