## 7.1 R² 量的是平均拟合

**本节依赖链：** 残差平方和 → 总变差 → R² → MAE → 平均拟合 ≠ 排序。

### 7.1.1 拆词与公式

| 中文 | 符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| \\(R^2\\) | coefficient of determination | \\(1-\\sum(y-\\hat y)^2/\\sum(y-\\bar y)^2\\)。1 = 完美；0 = 和「全猜平均数」一样糟；**可以为负** | 冻住：π 0.9844 / η 0.9561 / ṁ 0.9827 |
| MAE | mean absolute error | \\(\\frac1n\\sum\\|y-\\hat y\\|\\)，**带原单位** | η 的测试 MAE ≈ 0.0016 |
| \\(\\mathrm{SS}_{res}\\) | 残差平方和 | 预测错了多少：\\((y-\\hat y)^2\\) 加总 |
| \\(\\mathrm{SS}_{tot}\\) | 总变差 | 数据相对均值散开多少：\\((y-\\bar y)^2\\) 加总。**η 窄带（U01）让分母很小** |

\\[
R^2=1-\\frac{\\mathrm{SS}_{res}}{\\mathrm{SS}_{tot}}
=1-\\frac{\\sum_i(y_i-\\hat y_i)^2}{\\sum_i(y_i-\\bar y)^2}
\\]

\\(y\\) = 真值（标签），\\(\\hat y\\) = 预测，\\(\\bar y\\) = 均值。

**算例（5 个点演示，单位任意）。** 真值 y = [10, 12, 14, 16, 18]，均值 14；预测 ŷ = [10, 12, 14, 16, 30]（只有一个点炸了）：

1. \\(\\mathrm{SS}_{res}=(0)^2+(0)^2+(0)^2+(0)^2+(12)^2=144\\)；
2. \\(\\mathrm{SS}_{tot}=(10-14)^2+(12-14)^2+(14-14)^2+(16-14)^2+(18-14)^2=16+4+0+4+16=40\\)；
3. \\(R^2=1-144/40=1-3.6=-2.6\\)。

**反过来，另一个极端。** 100 个点里 95 个极准、5 个在边上炸，平均 \\(R^2\\) 仍可很高。而**优化偏偏爱往边上走**（U10 的 Pareto 在流形边缘）——所以平均分高不等于边上有用。

**两个必须记住的事实：**
1. **η 分母小，一点误差就砸 \\(R^2\\)**——所以 η 的 \\(R^2\\) 对误差**更敏感**，不是更钝（U01 窄带问题）。
2. **拟合好和排序对不是一回事。** 单调变换（把预测整体压一压或拉一拉）可以几乎不改 \\(R^2\\) 却换掉 Top-1；反过来也可能。优化要的是排序，不是平均分。

训练 0.99 / 测试 0.96 是**过拟合迹象**（U06），要诚实公开。

## 7.2 划分：随机留出证明什么、不证明什么

**本节依赖链：** 划分 800/100/100 → seed → val/test → 泄漏 → 多种子 → 流形 17.4 vs 6.1 → 外推。

### 7.2.1 拆词与数字

| 中文 | 一句定义 | 本项目数字 |
|---|---|---|
| 划分 | 把样本分成几份：训练 / 验证 / 测试 | **800 / 100 / 100** |
| seed / random_state | 随机种子：决定「怎么抽」。同一个 seed 每次抽一样，别人才能复现 | **42** |
| 训练集 train | 用来改参数的 800 组 | 800 |
| 验证集 val | 用来**早停和调超参数**的 100 组 | 100 |
| 测试集 test | 只许**终评一次**的 100 组 | 100 |
| 泄漏 | 测试集参与早停/调参 → 模型「偷看过」答案 → 分数虚高 |
| 多种子 | 换 seed 多训几遍看分数波动。**本项目没做**（Level 1 缺项，U12） |

**本项目划分证明什么：** 同分布随机 100 点上拟合好（E2）。

**不证明什么（三条）：**
1. 不是 PLAID **官方 test 200**（标签隐藏，算不出 \\(R^2\\)，U05）；
2. 不是按**几何家族 / 叶尖马赫 / 近堵塞**分层的划分——换一族叶子还好不好，没测；
3. 没有多种子平均——分数是这一次 seed 的结果。

**流形 3×（本章题眼数字）。** 标准化空间里，训练集内部最近邻**中位距离约 6.1**，Pareto 候选到训练集最近邻约 **17.4**，约 **3×**（U05 说过「流形」名字：74 维盒子里真正有叶子的地方）。+5.4% 更像**外推**，不像插值（U02 定义过两词）。口误「流初级」= 留出集。

**η 外推量的证据（三个数连起来读）。** Pareto 候选的 η 预测，超出其最近邻训练样本实测值的中位约 **0.0235**；测试集 η 的 MAE 约 0.0016；所以外推量 ≈ MAE 的 **14×**。平均分再好，边上是在 14 倍误差尺度上说话。

## 7.3 排序错了会怎样；决策指标为什么是 null

**本节依赖链：** 优化要的是排序 → 六个决策指标逐个定义 → 没有收敛 RANS → 全 null → 假 HV 事件 → 第一轮 8 点能填什么。

### 7.3.1 六个决策指标逐个钉死

优化要的不是平均 \\(R^2\\)，是**谁该进 Top-k 去跑贵的 RANS**（U04：RANS 是贵计算）。所以真正的考卷是下面六个：

| 指标 | 英文 | 问的是什么 |
|---|---|---|
| 秩相关 | Spearman / Kendall | 代理排序和 CFD 排序是否同调（用的是**秩**——第几名，不是原值） |
| Top-k Recall | top-k recall | 真前 k 里有几个被模型前 k 抓住。Top-5 分母是 5 |
| 可行性精度 | Feasibility Precision | 说可行的有多少真可行。**没有几何合法性定义时很难算** |
| Pareto 超体积误差 | Pareto HV Error | 代理前沿相对 CFD 前沿的超体积（前沿下方面积/体积，名字）误差 |
| 优化后悔 | Optimization Regret | 按代理选的点，CFD 上后悔多少。**必须用 CFD 定义** |
| CFD 预算节省 | CFD Budget Saved | 相对随机/全算，省了多少次真计算 |

**为什么全 null（U04 已钉，这里给原因链）。** 填这些数需要**收敛 RANS 对照**。现在只有：代理自己（E2）+ 一次未收敛粗网格（E3）。用代理自己和自己比来填这些数，叫做**伪造**。优化页曾经出现随代数线性涨的**假 HV**（代理自比出来的），已改成**破折号**。

**第一轮若只核 8 个点（高η低σ / 高η高σ / 对照——U08/U09 讲 σ）**，只能填很糙的 Spearman / Top-k；HV、Regret、Budget 仍空。

**郭老师先问排序，** 因为他关心「少算几次真 CFD、空间能不能探清」，不关心再要一个平均 \\(R^2\\)（U12 展开）。
