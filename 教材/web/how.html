怎么读这本书

验收两件事：发送包十问能自己答且不越档；每一句对外口径能指到仓库里的一个文件。

可当桥：导数、微分、向量、均值、标准差、压力。

必须从零认：马赫、等熵、激波、附面层、RANS、残差、代理、ONNX、留出集、R²、Dropout、覆盖率、Pareto、null、E0–E4。

旧版把证据档放第一章，桌上的东西还没认全。新顺序：机器 → 欧拉 → 激波 → RANS → 74 维 → 代理网 → R² → MC Dropout → 覆盖率 → Pareto → 证据档 → 郭老师线。

每一章：先认词表 → 画面到数据的六层 → 仓库指认 → 再做题。题只考本章已讲的词。日历不锁两周。
