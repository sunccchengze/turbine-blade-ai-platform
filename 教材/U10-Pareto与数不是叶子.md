## 10.1 多目标：不是三头都最甜

### 10.1.1 拆词

| 中文 | 英文/符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| 支配 | dominate | A 的所有目标都不差于 B，且至少一个更好 | A(η 0.90, ṁ 20) 支配 B(η 0.88, ṁ 19) |
| 非支配 | non-dominated | 点集里**没有**点支配它 | 前沿上的点 |
| Pareto 前沿 | Pareto front | 非支配点连成的权衡曲线：**一头再涨，另一头必掉** | 本项目 100 个候选 |
| NSGA-II | — | Deb 2002 的多目标优化算法：非支配排序 + 拥挤距离 + 精英保留 | 见下 |
| 种群 / 代数 | population / generation | 一代 = 一批候选解；一代代进化 | 种群 **100**、**200 代** |
| 拥挤距离 | crowding distance | 前沿上点有多「稀」。大的留下，前沿才铺开 |
| 精英保留 | elitism | 好解不丢，防止被随机冲掉 |
| 锁版 | locked | 对外只用 **pymoo 0.6.1** 跑出的 0.9173，不用 0.9212 | pymoo = 本项目用的优化库名字 |
| seed | random seed | 随机种子（U07 复习） | **42** |

**画面。** η 要高、ṁ 要大，往往**不能同时最优**——流量顶到堵塞边，η 就掉（U01/U03）。所以不存在一个「三头都最甜」的点，只有一条「此消彼长」的前沿。**三目标前沿其实是面，二维散点只是投影**（三个目标画在一个平面上必然丢一维）。

**操作与数字。** 本项目：种群 100、**200 代**、seed=42、pymoo 0.6.1。约束 \\(\\pi\\ge1.8\\)，\\(\\eta\\ge0.84\\)（U01）。得到 100 个非支配点（**代理意义上**）。第一层坐满：非支配点个数 = 种群。去掉 η≥0.84 约束，前沿往低 η 伸。**换 seed 43，0.9173 一般不会逐位一样**。pymoo 升到 0.6.2 曾漂到 0.9212——对外只用锁版。回放 200 代证明的是**优化算法动态**，不是物理收敛。

**搜的是特征空间，不是设计空间（U05）**——这句话贯穿本章。

## 10.2 三个端点；+5.4% 不能和 CFD 增益比

**三个端点（每个都要会背限定词）：**

| 端点 | 数 | 必须带的话 |
|---|---|---|
| 最高效率 | 0.9173097 | **代理**；相对训练均值 0.8703 为 +5.4% |
| 最大流量 | 21.7379 kg/s | 该点**代理** η≈0.873 |
| 最高压比 | 2.1073413 | **代理** |

**+5.4% 的算账。** \\((0.9173-0.8703)/0.8703\\approx 5.4\\%\\)。分母是**训练均值**，不是公开基准设计效率。训练数据本身的 η 最大值约 0.8914（E1 静态审计）——0.9173 连「训练样本里的最好」都超过了，这恰恰说明它**在外推区**（U07 流形 3×）。写成「比公开设计效率高 5.4%」错两处：分母不对 + 代理数没经 CFD。

**训练均值 ṁ ≈ 19.51 kg/s。** 最大流量 21.74 那点：公开机理是靠近堵塞、激波–分离、η 掉（U03）。**E2 的是两个数的配对；激波场不是我们拍的。**

**不能和谁比大小。** 季路成老师课题组（清华，名字）公开工作用 FFD + 伴随、**CFD 核过** +0.8%/+1.2%。我们的 +5.4% 是代理相对训练均值——**证据档不同，不能比大小**。

**假 HV 事件（U07 复习）。** 已改成破折号。对外动词只能是「**筛**」，不能是「找到最优」。

## 10.3 从向量到叶子缺哪些箭头

```
74 维向量
  --缺-- 合法几何（CST/FFD）        ← 缺
  --缺-- 体积网格                   ← 缺
  --缺-- 收敛 RANS                  ← 缺
  --缺-- 与基准的 CFD 对比          ← 缺
  --缺-- 结构/热/加工               ← 缺
→ 一片金属叶子
```

**每支箭头逐个说：**
1. **合法几何**：74 维是统计量（U05），没有 CST/FFD 反解。盒子内可能**没有可网格化原像**——74 维向量的「原像」（能映成它的那片几何）不保证存在。
2. **体积网格**：有了几何还要切网格（U04），一片新叶子要重新网格化。
3. **收敛 RANS**：relrms 到阈值（U04），我们只有 −3.39。
4. **与基准对比**：和 Rotor 37 基准的 CFD 对照——宋老师 GHG-01 的第一问就是「跑过真 RANS 吗」。
5. **结构/热/加工**：应力、温度、振动、寿命、公差，全没算。

**页上 3D 是什么。** **示意重构**：随滑块拧可能只是参数化预览，**不是这个向量的逆 CAD**。**生成页是库内近邻**（在已有样本里找最像的），不是扩散模型长新叶。厚度非负约束卡了，**没有解决可加工**。

**发送包标准答（Q3 收口，逐字背）：** 「不是。0.9173 是特征空间里代理吐的数。没有 CST/FFD，也没有收敛 RANS。」
