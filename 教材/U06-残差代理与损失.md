读完本单元，你必须能：

1. 说出代理是 \\(f_\\theta:\\mathbb{R}^{74}\\to\\mathbb{R}^3\\)（读法：输入 74 个数、输出 3 个数的函数）；
2. 默写残差块 \\(x\\mapsto\\mathrm{ReLU}(F(x)+x)\\)；
3. 写出损失 = 加权 MSE + 边界 ReLU²，并说明这**不是 PINN**；
4. 指出 ONNX 路径（`backend/models/surrogate_model.onnx`）和约 **2.11 MB / 523,011 参数**。

**桥（不需要重学）：** U01（代理、ONNX、R² 名字、η 窄带、权重 3、标签）、U02（422）、U03（η 接近跳变）、U05（74 维）；高中数学：函数、映射、平方、求和。

**本章依赖链：**

```text
函数 → 神经网络 = 多层线性 + 非线性
   → 神经元（权重 w·h + b）→ 激活 → ReLU → 分段线性

```

## 6.1 代理是一个函数，不是求解器

**本节依赖链：** 函数 → 神经元 → 权重/偏置 → 激活 → ReLU → 前向/反向 → 梯度 → 过拟合 → 参数量算例。

### 6.1.1 拆词

| 中文 | 英文/符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| 函数 | function | 高中数学：每个输入对应一个输出。这里 \\(f_\\theta(x)\\)：74 个数进去，\\((\\pi,\\eta,\\dot m)\\) 出来 |
| 参数 | parameters \\(\\theta\\) | 训练要改的数（所有权重和偏置的总称） | 本项目约 **523,011** 个 |
| 权重 / 偏置 | weights \\(W\\) / bias \\(b\\) | 每个神经元做的第一步：\\(w\\cdot h+b\\)（向量点乘 + 加一个数）。\\(w\\) 是权重，\\(b\\) 是偏置 |
| 激活 | activation | 非线性之后吐出的那个数。**Dropout 乘 0 的是它** |
| ReLU | Rectified Linear Unit | \\(\\max(z,0)\\)：小于 0 截成 0，大于 0 原样放行。整网因此是**分段线性连续函数** |
| 非线性 | nonlinearity | 不是直线的变换。没有它，多层线性叠起来还是一层线性 |
| 前向 | forward | 给定 \\(x\\) 和当前权重，算出 \\(y\\) |
| 反向 / 梯度 | backward / gradient | 损失对权重的**导数**（变化率）。Adam 沿着它走 |
| Adam | Adam optimizer | 一种带动量的梯度下降算法。lr（学习率）约 \\(10^{-3}\\)，早停耐心 40 |
| 过拟合 | overfitting | 训练误差远小于没见过的样本上的误差（背题背到只会默写） |
| 万能逼近定理 | universal approximation | 理论：足够宽的网络可以任意逼近**连续**函数。但有限宽有限深下，逼近接近阶跃的 η 需要非常多段折线 |

**画面与操作。** 输入 74 个数，输出三个气动标量。中间是若干层线性和 ReLU。它近似的是 **PLAID 那批 RANS 标签**（U01），不是在解 N-S（U04）。前向：算 \\(y\\)。反向：算 \\(\\partial L/\\partial\\theta\\)（损失对每个参数的导数）。训练就是反复改 \\(\\theta\\)。

**参数量算例。** 约 523,011 个参数，样本约 1000，大约 **500 : 1**——参数比样本还多。靠残差捷径、Dropout、权重衰减、早停（本章后面逐个定义）才没立刻崩。

**数据。** 训练 \\(R^2\\) 可到 0.99，留出测试约 0.96 档（η 0.9561）——差距要公开（U07 详谈）。分段线性连续函数难贴 η 在 SWBLI 附近（U03）的跳：**有限段折线不能精确表示阶跃**。

**边界。** 「神经网络就是 CFD」是错的：CFD 在格子上迭代守恒式（U04）；代理是拟合。ONNX 的意义：别人不用 PyTorch（训练框架名字）也能算，浏览器 WASM（浏览器里的高性能运行时名字）跑的是同一份文件。

## 6.2 残差块与训练期 Dropout

**本节依赖链：** 残差块 → 捷径 → BatchNorm → Dropout（inverted）→ eval() → Kaiming 初始化 → 架构默写。

### 6.2.1 拆词

| 中文 | 英文/符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| 残差块 | residual block | \\(x\\mapsto\\mathrm{ReLU}(F(x)+x)\\)：让 \\(F\\) **学增量**；\\(F\\approx0\\) 时退成恒等（输出=输入） | He et al., 2016 |
| 捷径 | skip / shortcut | 把输入原样加到 \\(F(x)\\) 上那根线。梯度可以抄近路 |
| BatchNorm | BN | 用当前批的均值方差把激活标准化，再学缩放平移（两个可学参数） |
| Dropout | dropout | 训练时以概率 \\(p=0.1\\) 把**激活**乘 0，留下的除以 0.9（inverted） | \\(p=0.1\\) |
| inverted dropout | — | 除 \\(1-p=0.9\\) 是为了训练和推理时激活的**期望一致** |
| eval() | eval mode | 推理模式：默认**关掉** Dropout |
| Kaiming 初始化 | Kaiming init | 针对 ReLU 的权重初始化方案（让一开始信号不炸不灭） |
| 隐层宽度 | width | 一层有多少个神经元 | 256、128 |

**画面。** He et al., 2016（残差网络论文）。与其逼一层学会整个映射，不如让它学「比恒等多出来的那一点」。最差 \\(F\\approx0\\)，块什么都没破坏。

**操作。** \\(F\\) 里：Linear → BN → ReLU → Dropout(0.1) → Linear → BN。整网：

```
74 → 256 + BN + ReLU + Dropout(0.1)
   → ResidualBlock ×3 (256)
   → 128 + BN + ReLU + Dropout(0.1)
   → ResidualBlock ×2 (128)
   → 3
```

输出层通常**没有** Dropout。训练期 Dropout 是**正则**（防过拟合的手段）：不要只靠某几个神经元。推理 `eval()` 关掉。**MC Dropout 是以后故意不关，见 U08。**

**边界。** 残差网络不是残差直方图（残差直方图是画预测误差的图，两码事）。去掉捷径，更深更难训。BN 用的 running stats 和随机面具一起开着做 MC 时会别扭——知道有此事即可。

## 6.3 损失：加权 MSE + 边界惩罚，不是 PINN

**本节依赖链：** MSE → 任务权重 w=(1,3,1.5) → 边界 ReLU²（带算例）→ 标准化空间 → PINN（为什么不是）→ Adam/早停/权重衰减/余弦退火/梯度裁剪 → 生产 ONNX 没有 Dropout。

### 6.3.1 拆词与公式

| 中文 | 符号/名字 | 一句定义 | 数字例子 |
|---|---|---|---|
| MSE | mean squared error | 预测与标签差的**平方**的平均 | 三路各自算 |
| 任务权重 | \\(w=(1,3,1.5)\\) | π 路 1、η 路 3、ṁ 路 1.5。η 因为窄带（U01）难拟合加倍盯。**超参数，不是定律** |
| 边界惩罚 | \\(\\lambda\\sum(\\mathrm{ReLU}(g_j))^2\\) | 输出越出盒子就罚。\\(\\lambda=0.1\\) | 见 6.3.2 算例 |
| PINN | Physics-Informed Neural Network | 在**配点**上把 PDE 残差（微分方程写出的差）写进损失。**本项目没有** |
| 早停 | early stopping | 验证集不再变好就停。耐心 40（连 40 轮不涨就停） |
| 权重衰减 | weight decay | 让权重往小里缩的正则。\\(10^{-4}\\) |
| 余弦退火 | cosine annealing | 学习率按余弦曲线降到约 \\(10^{-5}\\) |
| 梯度裁剪 | gradient clipping | 梯度太大就截断，防爆炸 |

\\[
L=\\sum_{i\\in\\{\\pi,\\eta,\\dot m\\}} w_i\\,\\mathrm{MSE}_i +\\lambda\\sum_j \\big(\\mathrm{ReLU}(g_j)\\big)^2
\\]

\\(g_j\\) 是四个越界量：\\(\\eta>1\\)、\\(\\eta<0.5\\)、\\(\\pi<1\\)、\\(\\dot m<0\\)。盒子**里面** ReLU² 是 0——惩罚只在越界时启动。\\(\\lambda=0\\) 时理论上可以吐 η=1.2；有惩罚才往回按。**η 下界 0.5 挡极端乱报，不是物理定律。**

**为什么加权。** 三个 MSE 量纲不同（π 无量纲、η 无量纲、ṁ kg/s），直接相加会被 π、ṁ 的数值淹没，所以加权。**标准化空间里的边界**由 `scaler_y`（输出方向的缩放表）从物理盒子变过来；先变到 scaled（标准化后）再算 ReLU。

**边界惩罚算例（假设 scaler_y 对 η 的均值 0.88、std 0.02——演示用假设数）。** 输出物理值 η=1.05：

1. 先到标准化空间：\\(s=(1.05-0.88)/0.02=8.5\\)；
2. 越界量 \\(g=s=8.5>0\\)，ReLU(g)=8.5；
3. 惩罚 = \\(\\lambda g^2=0.1\\times 8.5^2\\approx 7.2\\)，压进损失逼网络改。

**PINN。** 标志是损失里有 \\(\\|\\mathcal{N}[u]\\|\\) 这类 PDE 残差项。本项目**没有**在配点上算 N-S，也没有欧拉残差（U02）。信里必须说「不是 PINN」。「物理引导」最大合法强度只有两个：**输出盒子（边界惩罚）+ 输入 422（U02）**。

**边界。** 生产 ONNX **没有** Dropout 算子；WASM 跑同一份文件。损失下降了 ≠ SU2 残差到 −6（U04）——这是两种完全不同的「降」。
