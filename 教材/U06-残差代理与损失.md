# 第 6 单元 · 残差代理、ONNX 与损失

离开本单元，你必须能：说出代理是 f_θ:R^74toR^3；默写残差块 x↦ReLU(F(x)+x)；写出损失是加权 MSE + 边界 ReLU²，并说明这不是 PINN；指出 ONNX 路径和约 2.11 MB / 523011 参数。

U01 已会「代理代替再跑一次贵仿真」。本章把那个函数拆开：一层里有什么、捷径干什么、训练压的是哪一个标量。

---

## 6.1 代理是一个函数，不是求解器

先认词：

| 中文 | 符号 / 英文 | 一句操作定义 |
|---|---|---|
| 代理 | f_θ(x) | 用已有贵仿真当老师，训出的便宜映射。这里 xinR^74，y=(π,η,ṁ) |
| 神经元 | neuron | 一层里的一个标量：先做 w· h+b，再加非线性 |
| 权重 | θ 或 W,b | 训练要改的数。存在磁盘上，Dropout 不会把它删掉 |
| 激活 | activation | 非线性之后的那个数。Dropout 乘 0 的是它 |
| ReLU | max(z,0) | 小于 0 截成 0。整网因此是分段线性连续函数 |
| 前向 | forward | 给定 x 和当前权重，算出 y |
| 反向 / 梯度 | backward | 损失对权重的导数。Adam 沿着它走 |
| 过拟合 | overfitting | 训练误差远小于没见过的样本上的误差 |

**画面。** 输入 74 个数，输出三个气动标量。中间是若干层线性和 ReLU。它近似的是 PLAID 那批 RANS 标签，不是在解 N-S。

**操作。** 前向：算 y。反向：算 ∂ L/∂θ。训练改 θ。约 523011 个参数，样本约 1000，大约 500:1，靠残差捷径、Dropout、权重衰减才没立刻崩。

**数据。** 训练 R^2 可到 0.99，留出测试约 0.96 档（η 0.9561）。差距要公开。分段线性连续难贴 η 在 SWBLI 附近的跳：有限段折线不能精确表示阶跃。

**边界。** 「神经网络就是 CFD」是错的。CFD 在格子上迭代守恒式；代理是拟合。ONNX 的意义：别人不用 PyTorch 也能算，浏览器 WASM 跑的是同一份文件。

仓库指认：`notebooks/04_residual_physics_model.ipynb`；`backend/models/surrogate_model.onnx`。

## 6.2 残差块与训练期 Dropout

先认词：

| 中文 | 英文 | 一句操作定义 |
|---|---|---|
| 残差块 | residual block | x↦ReLU(F(x)+x)。学增量；F≈0 时退成恒等 |
| 捷径 | skip / shortcut | 把输入原样加到 F(x) 上，梯度可以抄近路 |
| Dropout | dropout | 训练时以 p=0.1 把激活乘 0，留下的除以 0.9（inverted） |
| BatchNorm | BN | 用当前 batch 的均值方差标准化，再学缩放平移 |
| `eval()` | eval mode | 推理默认关掉 Dropout |

**画面。** He et al., 2016。与其逼一层学会整个映射，不如让它学「比恒等多出来的那一点」。最差 F≈0，块什么都没破坏。

**操作。** F 里：Linear → BN → ReLU → Dropout(0.1) → Linear → BN。整网：

```
74 → 256 + BN + ReLU + Dropout(0.1)
   → ResidualBlock ×3 (256)
   → 128 + BN + ReLU + Dropout(0.1)
   → ResidualBlock ×2 (128)
   → 3
```

256、128 是隐层宽度。输出层通常没有 Dropout。训练期 Dropout 是正则：不要只靠某几个神经元。推理 `eval()` 关掉。MC Dropout 是以后故意不关，见 U08。

inverted dropout 除以 1-p=0.9，是为了训练和推理时激活的期望一致。BN 用的 running stats 和随机面具一起开着做 MC 时会别扭——知道有此事即可。

**边界。** 残差网络不是残差直方图。去掉捷径，更深更难训。Kaiming 初始化针对 ReLU。

## 6.3 损失：加权 MSE + 边界惩罚，不是 PINN

先认词：

| 中文 | 符号 | 一句操作定义 |
|---|---|---|
| MSE | mean squared error | 预测与标签差的平方平均 |
| 任务权重 | w=(1,3,1.5) | η 路 3，因为窄带难拟合。超参数，不是定律 |
| 边界惩罚 | λΣ(ReLU(g_j))^2 | 输出越出盒子就罚。λ=0.1 |
| PINN | Physics-Informed NN | 在配点上把 PDE 残差写进损失。本项目**没有** |
| Adam | Adam | 带动量的梯度下降。lr 约 10^(-3)，早停耐心 40 |

**公式。**


L=Σ_{i∈{π,η,ṁ}} w_i MSE_i +λΣ_j (ReLU(g_j))^2


g_j：η>1、η<0.5、π<1、ṁ<0。盒子里面 ReLU² 是 0。λ=0 时理论上可以吐 η=1.2；有惩罚才往回按。η 下界 0.5 挡极端乱报，不是物理定律。

三个 MSE 量纲不同，直接相加会被 π、ṁ 淹没，所以加权。标准化空间里的边界由 `scaler_y` 从物理盒子变过来；先变到 scaled 再算 ReLU。

**PINN。** 标志是损失里有 ‖N[u]‖。本项目没有在配点上算 N-S，也没有欧拉残差。信里必须说「不是 PINN」。「物理引导」最大合法强度：输出盒子 + 输入 422。

训练还用 weight decay 10^(-4)、余弦退火（lr 降到约 10^(-5)）、梯度裁剪防爆炸。这些是超参。损失下降了 ≠ SU2 残差到 −6。

生产 ONNX **没有** Dropout 算子。WASM 跑同一份文件。
