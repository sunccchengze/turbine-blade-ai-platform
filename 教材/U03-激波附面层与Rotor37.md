## 3.1 激波：超音速里的压力陡坎

**本节依赖链：** 超音速（U01）→ 激波 → 等熵波对比 → 正/斜/槽道激波 → R–H 压比公式（带算例）→ 逆压梯度。

### 3.1.1 拆词

| 中文 | 英文/符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| 激波 | shock | 超音速气流里一道**几乎不连续的坎**：几个网格内压强猛升、速度掉到亚音、熵增加（熵 = U01 定义的「乱」，穿过激波一定增加） | 见 3.1.2 算例 |
| 等熵波 | isentropic wave | 可逆、不增熵的弱扰动，如声波。**激波不是它** |
| 正激波 | normal shock | 来流垂直于波面的激波。同样来流马赫下，它的压比最大、损失最猛 |
| 斜激波 | oblique shock | 波面与来流不垂直。它的「法向马赫」更小，通常更弱 |
| 槽道激波 | passage shock | 叶栅通道（两片叶子之间的通道）里被两边壁面约束的那道激波，往往略斜 |
| 法向马赫 | normal Mach | 速度**沿波面垂直方向**的马赫数。斜激波的损失看它，不看总马赫 |
| 逆压梯度 | adverse pressure gradient | 顺着流动方向**压力升高**。流体要「爬这个坡」 |
| Rankine–Hugoniot | R–H 关系 | 正激波两侧压比、密度比随来流马赫数的公式（见下） |

**画面。** 超音速气流（U01：比声音快）撞上一道几乎不连续的坎：坎前快、压强较低；坎后突然变慢、压强升高。坎很薄，数值网格上通常只占几个格子。它不是声波：声波可逆、等熵、很弱；激波不可逆，穿过它熵一定增加。口误「基波」一律改回**激波**。

### 3.1.2 公式与算例

正激波压比（\\(\\gamma=1.4\\)，U01 学过 γ）：

\\[
\\frac{p_2}{p_1}=1+\\frac{2\\gamma}{\\gamma+1}(M^2-1)
\\]

**完整算例（\\(M=1.48\\)，就是叶尖公开基准马赫数）：**

1. \\(M^2-1=1.48^2-1=2.1904-1=1.1904\\)；
2. \\(2\\gamma/(\\gamma+1)=2.8/2.4\\approx 1.1667\\)；
3. \\(p_2/p_1=1+1.1667\\times1.1904\\approx 1+1.389\\approx 2.39\\)。

一道正激波能让压强当场变成约 2.39 倍。**但叶栅里不能直接用这个数**：通道里是斜的、三维的，还有附面层（3.2 定义）。这个式子只建立数量级直觉：**来流马赫升高，激波压比升高、损失更猛**。

**波后必亚音（正激波）**：波后马赫数 < 1。波后压力陡升 → 顺着流向压力升高 → 这就是**逆压梯度**。

**边界。** 斜激波的法向马赫小于来流马赫，通常比正激波弱。叶栅里常见槽道激波，不要当成孤立正激波作业题。

## 3.2 附面层，以及激波打在它上面

**本节依赖链：** 无滑移 → 附面层 → 层流/湍流/转捩 → 吸力面/压力面 → 逆压梯度爬坡 → SWBLI → 分离 → 掺混损失 → 喉部复习 → η 对激波位置极敏感。

### 3.2.1 拆词

| 中文 | 英文/符号 | 一句定义 | 数字例子 |
|---|---|---|---|
| 无滑移 | no-slip | 壁面上流体速度 = 壁面速度；静止壁就是 0 | 贴墙那层空气的速度 = 0 |
| 附面层 | boundary layer | 贴壁的**薄粘性剪切层**：壁面速度 0，往外很短距离内恢复到主流速度。它是流动结构，不是氧化膜 | 厚度毫米量级 |
| 粘性 | viscosity | 流体内部分子间摩擦的「劲儿」。附面层里它起主导作用 |
| 层流 / 湍流 | laminar / turbulent | 流体一层层平滑流 / 乱流。附面层里两种都可能是 |
| 转捩 | transition | 附面层从层流变成湍流 |
| 吸力面 / 叶背 | suction side | 压力较低、气流加速的那一面（叶背） |
| 压力面 / 叶盆 | pressure side | 压力较高的那一面。**高是因为气流折转，不是「凹坑挤气」** |
| 分离 | separation | 近壁流体不再贴壁向下游走，出现回流或脱离。形成「分离泡」 |
| SWBLI | shock-wave / boundary-layer interaction | **激波的逆压打在附面层上**，层变厚甚至分离 |
| 喉部 | throat（U01 复习） | 相邻叶片通道最窄截面。堵塞发生在这里 |

**画面。** 壁面上速度必须是 0（无滑移）。往外很短的距离内速度爬回主流——这一薄层就是附面层。吸力面气流加速、压力低；压力面气流折转、压力高（因果别反：是折转让压力高，不是「凹坑挤气」）。

**拆词：层流与湍流。** 层流摩阻小、**抗逆压弱**（顶不住压力爬坡，容易分离）。转捩成湍流后更能抗分离，但掺混损失更大。吸力面附面层本来就在逆压里爬坡——它是分离的高发区。

**操作：激波一立，会发生什么（把链走一遍）。** 激波一立 → 波后压力陡升（3.1.2 的 2.39 倍量级）→ 逆压梯度打在吸力面附面层上 → 层变厚，重则**分离** → 分离泡里低能流体和主流掺混，熵跳一下 → η 掉。

**为什么 η 比 π 尖（本章最重要的一问）。** η 对「激波站在弦向何处」（弦向 = 沿叶片前后方向）**极敏感，接近间断**：激波往前挪一点点，分离范围就变，效率就跳。而 π 是进出口总压的积分（U01：出口总压 ÷ 进口总压），对激波位置没那么敏感。所以同样大小的预测误差，砸在 η 上比砸在 π 上疼得多——这就是 U01 说的「η 窄带难拟合」的物理根源。

**喉部复习（U01 已定义，这里落到几何上）。** 喉部先到声速。再降背压，\\(\\partial\\dot m/\\partial P\\)（流量对背压的变化率）接近 0——堵塞。**喉部是通道最窄截面，不是燃烧室进口**（燃烧室是压气机后面的部件，本项目根本没算它）。

**数据。** 代理最大流量点 \\(\\dot m\\approx 21.74\\,\\mathrm{kg/s}\\) 时 \\(\\eta\\approx 0.873\\)，相对 0.9173 掉了一截（两个数都是 U01 学过的代理端点）。叙事：靠近堵塞，槽道激波增强，吸力面分离。**这两个数是代理点（E2，名字），激波掀附面层是公开机理直觉，不是我们拍到的场——我们没有任何激波照片。**

**边界。** 把激波抹成等熵压缩（当成没有损失的压缩）会**高估** η。优化页请郭老师看最大流量附近，是为了看见「流量顶上去、效率掉下来」的权衡，不是只看 0.9173。

## 3.3 Rotor 37 是谁，不是谁；位置以后会被抹掉

**本节依赖链：** Reid & Moore（名字）→ Rotor 37 高负荷进口级 → PLAID 几何变 + 工况变 → 叶高 0/100% → 74 维（U05 伏笔）→ η 跳与 ReLU 网（U06 伏笔）→ 覆盖率 65%（U09 伏笔）。

### 3.3.1 拆词与事实

| 中文/名字 | 一句定义 |
|---|---|
| Reid & Moore | NASA Rotor 37 的**原始公开报告作者**（1978 年量级的文献）。记住「有原始出处」这个习惯 |
| 高负荷 | 一级里压得多、折转大、马赫高——负荷高，所以它身上激波问题典型 |
| PLAID 变分 | 数据集里既改**几何**（叶片形状微变），又改**工况**（Ω、P）。两个维度都在变 |
| 叶高 0% / 100% | 0% = 轮毂（贴轴），100% = 叶尖（U02 已定义） |

**Rotor 37 是谁（U01 已钉，这里再钉一次）：** NASA 公开的跨音速**压气机转子**基准件，CFD 公共考题。不是涡轮、不是风扇整级、不是涡扇。KIT 303 秒是行业引子，不是本项目对象。

**公共考题的好处与坏处。** 好处：全世界能对照，别人可以复现。坏处：它**不是你家可铣的几何家族**——它是别人定死的一片叶子，你在它的变分里学，不等于你能设计新叶片。

### 3.3.2 位置被抹掉的伏笔（U05 才展开，这里先挂链条）

U05 会把每个样本收成 74 个数（9 组场 × 8 个统计量 + Ω + P）。那是**全局统计**：激波在弦向、叶高上的**位置**进不去。于是：

- 网络只能**平滑地贴**一个接近跳变的 η（网络是一段段折线拼的连续函数，U06 拆 ReLU）；
- 后文 Dropout 抖的是有效权重（U08），抖不出「激波在 70% 叶高」；
- 这就是 U08–U09 里 **η 覆盖率只有 65%** 的伏笔。

现在先记住这条链的**两头**：激波位置（本单元）→ 被 74 维抹掉（U05）→ η 难拟合难覆盖（U07–U09）。

**PLAID 场量有压力，为何仍说看不见激波位置？** 数据集原始样本的表面上**有**压力场。但我们的特征化只用它的**统计量**（均值、偏度……），统计完之后没有空间下标，位置被捏没了。就像你只知道「全班平均分 90、有人考了 100」，却不知道那个 100 分坐在第几排。

**边界。** 「1.48 → 激波 → SWBLI → η 跳 → 统计丢掉位置 → 覆盖率 65%」这条链，每步的证据档不同：1.48 是公开基准（E1 静态）；激波掀附面层是公开机理直觉；21.74@0.873 是代理点（E2）；65% 是留出集覆盖率（E2）。谁把「我们看见了激波」说出口，直接越档。
