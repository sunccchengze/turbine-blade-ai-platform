# 第 0 幕 · 开场与地图（20 min）

**目标**：让学生知道"今天要发生什么" + 建立信任 + 立规矩
**Hook**：「你们猜，这个平台是几个人、用了多长时间做出来的？」

**流程**：
1. **自我介绍**（2 min）：「我是孙承泽，大二。你们今天来的这个项目——我用 3 个日历日、和一个人工智能 Agent 结对，做出了一个完整的 AI 工程平台。今天 4 小时，我把整个过程里所有的名词、所有的方法、所有的坑，全部拆给你们看。」
2. **Hook 揭晓**（2 min）：全场猜人数/天数，揭晓「1 个人 + 1 个 AI Agent + 3 天 = 39 天工作量」。→ 顺势抛出：「所以我今天讲的不只是叶片，是**一套你们马上要用的工作方式**。」
3. **全景图**（5 min）：一页画出 12 个概念节点（叶片→数据→特征→神经网络→R²→UQ→NSGA-II→Pareto→平台→验证→Transformer→Agent），指着说：「今天结束时，这张图里每一个词，你都能用自己的话解释。**这是我们的契约。**」
4. **立规矩**（3 min）：
   - 「任何时刻，听不懂就举手打断——我重讲，直到你懂为止」；
   - 「我问问题，你们大声答，答错了我给你鼓掌（答错=暴露盲区=今天赚到了）」；
   - 「今天不讲公式推导，讲**为什么**和**直觉**。公式是给大一之后的你们留的礼物。」
5. **埋钩子**（3 min）：「结尾我留了 15 分钟，告诉你们：想加入这个项目/想复现它，从哪个文件开始。**今天的最后一张 PPT 是你们的入学地图。**」
6. **热身检查点**（2 min）：「涡轮和压气机，一个是吃能量一个是吐能量——猜猜哪个是发电的？」（答：涡轮）——先测语感，不评价对错。

# 第 1 幕 · 物理世界（25 min）

**目标**：理解工程师在算什么 + 三个指标 η/π/ṁ + CFD 为什么慢
**Hook**：「飞机引擎每秒吞进几公斤空气，你们猜猜——为什么叶片形状决定飞机的命？」

**流程**：
1. **叶轮机械**（5 min）：风扇→吸尘器→飞机引擎→燃气轮机。类比"大风扇"。互动：「你们家里什么东西有叶片？」（风扇、吹风机、洗衣机…）→ 所以叶轮机械=靠转动的叶片跟空气/水"交换能量"的机器。
2. **一对兄弟：压气机 vs 涡轮**（5 min）：打气筒（耗能压缩）vs 气球放气（产功推动）。互动：「医院氧气瓶上的表，是压气机还是涡轮？」（压气机——它在压缩氧气）。
3. **KIT 故事**（5 min）：2026.2 德国 KIT 无压气机燃气轮机 303 秒破 NASA 250 秒纪录；传统燃气轮机一半功率拿去转压气机。互动：「如果把压气机拿掉，谁的压力最大？」（叶片设计师——瓶颈转移了）。
4. **三个指标 η/π/ṁ**（5 min）：效率=转化率（充电宝 88%）、压比=压缩几倍（打气筒）、流量=胃口多大（水龙头）。互动：「效率能超过 100% 吗？」（不能，能量守恒）——埋下"物理约束"伏笔。
5. **CFD：虚拟风洞**（5 min）：CFD=电脑里搭风洞；RANS=求平均的偷懒大法；网格=叶片高清照片的像素点（29,773 个）。互动：「一次 CFD 要多久？猜猜看」→ 几小时。→ 引出：「设计师想试一万种叶片，一次几小时——**这就是整个项目的起点：太慢了。**」

**检查点（3 问）**：
- 「η 高好还是低好？」（高）
- 「为什么效率不可能超过 1？」（能量守恒）
- 「CFD 慢在哪一步？」（每个候选都要几小时算）

**收尾钩子**：「如果有个'速算员'能 1 毫秒给出同样的答案，工程师要还是不要？——要，但前提是……你们待会儿会自己发现前提是什么。」

# 第 2 幕 · 数据（25 min）

**目标**：数据从哪来、为什么是 74 维、特征=体检表、诚实披露
**Hook**：「速算员上岗前，得先'见过'足够多叶片——它的教材是什么？」

**流程**：
1. **公开题库 PLAID/Rotor37**（5 min）：NASA 的经典压气机 + PLAID 团队用 CFD 批量算好 1,000 组（叶片变+工况变）公开出来。互动：「为什么公开数据集重要？」（可复现/可对比/不用自己花几万小时算）。
2. **像素点→体检表**（5 min）：29,773 节点×9 场量=27 万个数，太大 → 压缩成 74 项体检指标。**先讲维度灾难**：「10 道判断题有 1024 种答案组合，你只有 5 份试卷——数据不够，维度越多越崩。」→ 所以 9 场量×8 统计量+Ω/P=74 维。
3. **8 个统计量逐个讲**（8 min）：拿"全班成绩"当例子：mean=平均分、std=分散程度、min/max、p25=后 25% 的线、p75、skew=偏不偏（是不是两极分化）、kurt=尖不尖。互动：「两个班平均分一样，怎么分辨谁更稳？」（std 更小=更稳）。
4. **诚实披露**（4 min）：「体检表丢了'压力峰值在叶片哪个位置'这个信息——这是故意的，为了 1,000 个样本能训练。代价我们认，而且写在 README 里。」互动：「你觉得这个代价值不值？」（开放讨论——引出"工程就是取舍"）。
5. **埋悬念**（3 min）：「官方还有 200 组'保密卷'——只有考纲（工况），没题目没答案。为什么？你们先猜，第 4 幕揭晓。」

**检查点（3 问）**：
- 「为什么不用 27 万个原始数直接喂 AI？」（维度灾难/数据不够）
- 「skew 大说明什么？」（分布歪/两极分化）
- 「体检表丢了什么信息？」（空间分布）

# 第 3 幕 · AI 模型（50 min）★核心幕

**目标**：神经网络、训练、R²、过拟合、物理约束、部署——从 0 建起"AI 猜得准"的直觉
**Hook**：「现在把 74 项体检表和 3 个成绩单，同时给一个'万能函数机'——它怎么学会从体检表猜成绩？」

**流程**：
1. **机器学习范式**（5 min）：不是写规则（"如果压力大就效率高"——规则写不完），是**给例子学规律**。互动：「让 AI 学会认猫，是写'猫=尖耳朵+胡子+…'还是给它 10 万张猫图？」（后者）。
2. **神经网络=超级函数**（8 min）：y=f(x) 初中就会——这里是 f(74个数)→3个数；里面的"旋钮"（参数）523,011 个。互动：「如果只有 3 个旋钮，能拟合多复杂的规律？」（简单）→ 旋钮越多越能拟合复杂规律，但数据不够就过拟合——先埋，后面细讲。
3. **残差连接=高速公路**（7 min）：「层数越深越聪明吗？不一定——信息传 100 层会'迷路'（退化）。残差连接给每层开条直通道，最差也不比浅层差。」（接力赛类比）→ 这就是项目模型的核心结构。互动：「残差连接解决什么问题？」（层深了学不动/退化）。
4. **训练=下山**（8 min）：损失函数=误差尺子（射箭离靶心多远）；梯度下降=蒙眼下山（往最陡方向迈）。互动：「怎么判断模型在进步？」（loss 在降）。→ 训练 200 轮（epoch），CPU 上跑完。
5. **物理约束**（5 min）：「模型可能说出'效率 120%'这种违反物理的答案——我们在损失里加惩罚，说了就扣分。」互动：「这算模型懂物理吗？」（不算，只是被罚——诚实：边界裁剪级，PINN 是 future work）。
6. **R² 与过拟合**（8 min）：R²=猜得准的分数（98 分）；过拟合=背答案的学痴（训练 99 分、考试 96 分——差距如实公开）。互动：「训练 99、测试 96，说明什么？」（背了一点点答案，但总体学会规律了）。
7. **对照实验**（4 min）：「我怎么知道残差网络好？跟基线 MLP 比（0.9132→0.9561）；纯点云模型效率只有 0.6076——这个失败我们也记录。为什么？」（只有记失败，成功才有意义——科学方法）。
8. **部署 ONNX**（5 min）：模型打包成"MP3 格式"（ONNX 2.11MB），任何机器毫秒级跑。互动：「为什么要转格式？」（体积 500MB→2.11MB、快 5 倍、不用装训练框架）。

**检查点（5 问）**：
- 「神经网络是什么的超级版？」（函数）
- 「残差连接解决什么问题？」（退化/层深学不动）
- 「R²=0.98 是什么意思？」（猜中 98% 的变化）
- 「过拟合像什么？」（背答案）
- 「物理约束是 PINN 吗？」（不是，只是边界惩罚——诚实）

# 第 4 幕 · 验证与优化（45 min）

**目标**：UQ（AI 会说"没把握"）+ 多目标优化（鱼和熊掌）+ 证据链（给自己挑刺）+ 信任链（RANS 终审）
**Hook**：「速算员猜得挺准——但你怎么知道它**这次**没猜错？它自己知道吗？」

**流程**：
1. **UQ：AI 的自我认知**（10 min）：MC Dropout=同一题问 10 遍看答案散不散（10 个同学蒙题类比）；置信区间=模型说"真值 95% 在这范围内"；覆盖率=检验这句承诺兑现没兑现（天气预报类比）。
2. **诚实披露（全场价值观高点）**（8 min）：「我们的承诺 95%，实测只兑现了 65–89%——效率最差 65%。**我们选择把这事公开放到网站和 README 上。**为什么？因为不说，评委也会算出来——主动说，是信任的开始。」互动：「你们觉得，主动承认模型不完美，会减分还是加分？」（讨论：工程诚信=长期加分）。
3. **修复路线 P2**（5 min）：Deep Ensembles=三个同学独立答再综合；Conformal=拿"往届真题"校准区间到真 95%。结果：65%→93.5%。「方法有缺陷不可怕，可怕的是不知道有缺陷。」
4. **多目标：鱼和熊掌**（7 min）：买手机类比（拍照 vs 电池）→ Pareto 前沿=所有"不亏本"的折中。互动：「为什么没有一个'最好'的方案？」（两个目标冲突——效率高往往流量掉）。
5. **NSGA-II=进化**（7 min）：达尔文类比——100 个方案杂交/变异/优胜劣汰 200 代，剩 100 个非支配解。互动：「'非支配'什么意思？」（没有别的方案在两个目标上同时比它好）。
6. **证据链自查（全场方法论高点）**（8 min）：优化完别急着吹，四个问题：①解的体检指标出格没？（0 越界✅）②离见过的数据多远？（中位 17.4 vs 内部 6.1——在边缘⚠️）③"超越训练样本"多少是靠外推？（η 超出近邻实测 0.0235=MAE 的 14 倍⚠️）④模型在附近区域准不准？（四层误差持平✅）→ 结论：「**这些解是代理模型的预测，不是物理事实。**我把它写在了网站首页——你们看，首页写的是'代理模型预测的最优设计'，不是'AI 找到的最优设计'。」
7. **信任链闭环（回收悬念）**（5 min）：RANS=高考（模拟考不算数）→ SU2 已跑通（今天给你们看了截图：残差 1e-14）→ top-3 解的 RANS 对照 8/10 前出。「**代理预测→证据链自查→RANS 终审**——这就是这个项目的方法论骨架，也是你们以后做任何 AI 工程都要走的路。」

**检查点（4 问）**：
- 「MC Dropout 怎么测模型有没有把握？」（问 10 遍看散不散）
- 「我们主动披露了 UQ 什么缺陷？」（名义 95% 实际 65–89%）
- 「Pareto 前沿上的点为什么没有'最好'？」（目标冲突）
- 「为什么 Pareto 解还要 RANS 验？」（代理预测≠物理事实）

# 第 5 幕 · 工程解剖（30 min）

**目标**：仓库地图 + 追一条数据链路 + 可复现性——"打下手"视角
**Hook**：「现在你们知道模型怎么学了——但'平台'到底是怎么把这些串起来的？跟我拆仓库。」

**流程**：
1. **仓库地图**（10 min）：打开 GitHub 仓库，逐目录讲（对照仓库树）：
   - `data/` 原材料（CSV 特征表）
   - `models/` 成品（scaler + ONNX）
   - `backend/` 厨房（FastAPI 后端 + 推理 + 复现脚本）
   - `frontend/` 菜单（React 网页）
   - `notebooks/` 实验室记录（1-6 号，从数据探索到 NSGA-II）
   - `docs/` 论文与档案（devlog、战报、答辩材料）
   - `scripts/` 一键复现工具
   - 互动：「猜猜哪个目录是'实验记录本'？」（notebooks）
2. **追一条链路**（10 min）：用户拖动滑块（前端）→ 74 个数发给后端（API）→ 标准化（scaler 体检表对齐）→ ONNX 推理 0.115ms → 反标准化 → 3 个数回前端画出来。「从你手指到数字，全程 1.85 毫秒。」互动：「如果用户把转速拉到 5000（超出见过的 1800），会发生什么？」→ 422 越界保护=速算员拒绝超纲题。「**宁可拒绝，不给错误答案。**」
3. **可复现性=科学诚信**（7 min）：seed 42=随机种子固定（抽签前定好）→ 重跑一模一样；锁版=依赖版本锁死（pymoo 0.6.1 vs 0.6.2 结果就从 0.9173 漂到 0.9212——我自己踩过）；`reproduce_r2.py` 10 秒出数。互动：「为什么'别人能复现'这么重要？」（数字是真的才敢信）。
4. **现场演示**（3 min，可选）：`python backend\scripts\reproduce_r2.py` 现场跑出三行 R²。「PPT 上的数字，10 秒验证。」

**检查点（3 问）**：
- 「从滑块到数字，经过哪三层？」（前端→API→模型）
- 「422 是什么？为什么要有？」（超纲拒绝，不瞎编）
- 「seed 42 是干嘛的？」（固定随机，保证可复现）

# 第 6 幕 · AI 世界观（30 min）

**目标**：Transformer/Attention/LLM/Agent——从"聊天"到"工程"的跃迁
**Hook**：「你们都在用 ChatGPT 聊天——但你们知道它'脑子里'长什么样吗？以及——**这个项目是怎么被 AI 做出来的？**」

**流程**：
1. **Transformer/Attention**（8 min）：读长难句先扫全句找主谓宾=注意力机制（划重点类比）；Transformer=让 AI 同时看全句、自己决定重点看哪。互动：「为什么'只看前一个词'不够？」（长句里重点可能在后面——比如'虽然…但是…'）。
2. **Token/Embedding**（5 min）：文字切成小块（token）→ 每个小块变成数字坐标（embedding）——"苹果"和"水果"坐标近。→ 连接本项目：「我们给叶片做的 74 维体检表，本质也是一种 embedding——把叶片变成数字坐标。」
3. **LLM=超级接龙**（5 min）：接龙大师，词库=全网。互动：「为什么它有时胡说八道？」（接龙接顺了但没查证）→ 引出 RAG=开卷考（塞参考资料，别瞎编）→ 我们给 Agent 的 HANDOFF.md 就是这个思路。
4. **Agent=会干活的实习生**（7 min）：聊天=复读机，Agent=查资料/跑代码/看结果/决定下一步。互动：「你们觉得 Agent 和聊天机器人最大区别？」（会做事+闭环）。
5. **我的真实工作流**（5 min）：展示本项目怎么和 Agent 结对：Agent 写代码/执行 → 承泽验收/决策 → 3 天 39 个开发日。「**你们马上要学的，就是让 AI 从'聊天'升级成'干活'——这是大学第一课。**」

**检查点（3 问）**：
- 「Attention 是干嘛的？」（自己决定重点看哪）
- 「embedding 是什么？」（把词/物体变成数字坐标）
- 「Agent 比聊天机器人多什么？」（工具+循环=会干活）

## 🎯 附：备用 Q&A（学生可能问的）

| 问题 | 一句话答案 |
|---|---|
| 为什么不用真实实验数据？ | 公开基准=可复现+可对比；真实实验数据昂贵且保密 |

| Agent 写代码，那你在干嘛？ | 提需求、验收、决策、背锅——**工程判断力**是 AI 给不了的 |
