## 0. 一句话总纲

> **生成器（扩散）出方案 → 场级代理（P1）百万级快筛 → 校准不确定度（P2）标红不放心区域 → SU2（P4）精验证 top-k → 结果回灌重训（数据飞轮）→ LLM 助手（E5）解释与决策。**

项目身份从「AI 判卷老师（预测性能）」升级为「**AI 出题老师（生成设计）+ 闭环教练（验证迭代）**」。

## 1. 现状基线（先复现，再动工）

- 现有模型：74 维统计特征 → 残差 MLP（测试集 R² π 0.9844 / η 0.9561 / ṁ 0.9827，口径：留出测试集 n=100, random_state=42, ONNX 实测，脚本可复现）

## 2. 五层架构（每层：做什么 / 怎么做 / 引用依据 / 平台亮点 / 数字口径）

### P1 场级几何感知代理（先做，最稳）
- **做什么**：放弃 74 维统计特征，直接消费表面点云（29,773 → 下采样 ~2k–5k 点）。输入：点坐标 + 工况(Ω,P)；输出：全表面压力/温度场 + 三标量(π,η,ṁ)。
- **怎么做**：两条路线并行小规模验证后选优——(a) **PointNet**（轻量、Colab 都能跑、天然处理无序点云）；(b) **FNO**（规则化网格上做场预测，叶栅方向 2025 年论文 MSE 达 10⁻⁶、单样本 56.8 ms）。GNN 作为进阶选项（罗罗德国 ASME J. Turbomachinery 2025 有工业级先例）。
- **引用依据**：PE-FNO (Phys. Fluids 2025, +13.3% 精度)；FNO 叶栅流场 (Aerospace Sci. Tech. 2025)；PIFNO + 迁移学习 (2024/25, 3/10 数据达同等精度)；C(NN)FD (MAE<0.05%, 900×)。
- **平台亮点**：3D 叶片上实时渲染预测压力/温度热力图（复用现有 Three.js 叶片，把场贴上去）。
- **数字口径**：场误差用相对 L2/MAE（对标文献 <1–5%）；标量沿用 R²（测试集口径一致）；对比表「74 维 MLP vs 场级模型」。

### P2 校准不确定性（Deep Ensembles + Conformal）
- **做什么**：把 65–89% 覆盖修复到「统计上严格 ≥95%」。
- **怎么做**：(a) 5 个种子训 Deep Ensemble，预测均值 + 方差；(b) 用留出校准集算 nonconformity score（绝对残差），分位数校准成预测区间；(c) 可选局部化 conformal 处理异方差（JCP 2026-05 专门做过 PINN/MC-Dropout 的 conformal 校准，直接对口）。
- **引用依据**：JCP 2026-05（conformal 校准 PINN UQ + 局部化方法）；Nature Commun. Eng. 2025-11（安全关键场景校准精度提升 12×）。
- **平台亮点**：UQ 页从「诚实承认覆盖不足」升级为「校准曲线：名义 95% = 实测 95%」。
- **数字口径**：empirical coverage、平均覆盖偏差（ACD）、区间宽度；新旧方法并列表。

### P3 条件扩散生成式反设计（核心跃迁）
- **做什么**：给目标（η, π, ṁ, 工况）→ 生成叶片几何。NSGA-II 降级为校验器/基线对照。
- **怎么做（防翻车路线）**：
  1. Rotor 37 表面点云下采样（~2k 点）+ 归一化对齐；
  2. **VAE** 把几何压进潜在空间（AirfoilGen 路线：autoencoder 保证几何有效性内嵌）；
  3. 潜在空间里训**条件扩散模型**（以目标性能为条件）；
  4. 条件采样 → 解码回几何 → 用 P1 代理 + P4 SU2 验证。
  5. 先 2D 叶型跑通（Bernstein 参数化，DLRK 2024 奠基），再上 3D 点云（2026-07-29 新论文证明直接 3D 坐标可行：解精度 99%、不可行 <1%）。
- **引用依据**：3D Turbomachinery Generative Diffusion (arXiv 2607.27093, 2026-07-29)；AirfoilGen (arXiv 2605.20303, 条件命中 98.41%, 20 万翼型数据集)；DLRK 2024 翼型扩散。
- **平台亮点**：「生成图库」——用户输入目标性能，一键出 10 个候选叶型（多样性展示 + 点击看预测性能 + 3D 对比）。
- **数字口径**：条件命中率（目标 vs 实际预测偏差）、几何有效性比例、解多样性（分布对比，引用论文的验证法）、生成-验证全链路成功率。

### P4 SU2 真实 CFD 闭环（承泽已拍板：要真闭环）
- **做什么**：搭「生成 → 代理筛选 → SU2 精验证 top-k → 回灌训练集 → 重训」主动学习飞轮。
- **怎么做**：SU2（开源 RANS，MIT 许可）支持多排叶轮机械（混平面接口 + 离散伴随，AIAA J. Propulsion 2020 验证）。CPU 可跑，单场约 30–60 分钟 → 每次闭环跑 10–20 场足够演示。Docker 化部署，跑批脚本化。
- **引用依据**：SU2 多排叶轮机械扩展 (AIAA J. Propulsion, 2020)；VortexNet 多保真 GNN (AIAA 2025) 展示「低保真+高保真修正」思想。
- **话术升级**：从「用公开数据，没跑过 CFD」→「搭了一条 AI+CFD 主动学习数据飞轮：代理广撒网、CFD 精验证、结果回灌越用越准」。
- **诚实口径**：SU2 与 PLAID 商业求解器结果定位为「相对趋势验证」（quantitative 对不上属正常，写成讨论点），加速比口径改为「AI+CFD 混合流程」下整体机时节省的实测。
- **平台亮点**：Optimize 页新增「验证状态」徽章（代理预测 vs CFD 实测）；Pareto 解标注「已 CFD 验证」。

### E5 LLM 设计助手（收尾锦上添花）
- **做什么**：自然语言设计意图 → 自动调参 → 调用 P1 代理 → 返回结果 + 解释。
- **怎么做**：接 Qwen/DeepSeek API（不必本地微调）；工具调用模式（function calling）调现有 API（predict/sweep/pareto）；前端加「设计助手」对话面板。
- **引用依据**：CFD-copilot（arXiv 2512.07917, 2025-12；中文航刊 2026-06）：领域适配 LLM + 多智能体 + MCP 实现自然语言 CFD 全流程。
- **平台亮点**：演示台词「帮我把效率提到 0.91，流量别低于 21」→ 助手调参 + 出图 + 解释权衡。

## 6. 风险与降级（承泽拍板全方案，但要有后手）

| 风险 | 应对 |
|---|---|
| 3D 扩散过拟合（仅 1000 样本） | VAE 潜在空间 + 2D 先通 + 几何扰动增强；不行则生成 2D 叶型 + 展向堆叠 |
| 本地 GPU 显存不够 3D 场模型 | 下采样 2k 点 + PointNet；FNO 用 2D 表面场 |
| SU2 精度对不上 PLAID | 定位「相对趋势验证」，写入讨论点 |
| 时间不够 | 裁剪顺序：P1→P2→P3→P4→E5，前面是硬通货，E5 可砍 |
