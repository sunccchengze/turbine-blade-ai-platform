## 2026-08-13 · A0 · 零先验，不是已经会

- **原话（大意）**：把我当智障来对待都行；图像优先；每个名词当场定义；不要假设我会。
- **当时理解**：降低门槛，从零讲。
- **后来证明不够**：只降低门槛，没有规定深度，也没有禁止童话腔。被 A1 修正。
- **仍有效的部分**：
  - 不假设先验。
  - 先给图再给式。
  - 名词首次出现必须定义。
  - 口误要改：基波→激波，负面层/覆面层→附面层；八个统计量里是 **std** 不是方差。

## 2026-08-13 · A1 · 深入浅出，禁止儿童故事，禁止生词硬猜（当前有效）

- **原话**：
  - 「你这么讲还是没有把握好那个度。」
  - 「74 维你说成什么成绩单？还总结数字？还什么收不收得住？收敛这种词关键词你总得体现出来吧？」
  - 「你现在根本就不是说把我当成智障去讲，你现在是完全不给我把深度东西讲出来了，你只让我了解了个大概就过去了。但是我做科研，我怎么可能只了解这个大概呢？」
  - 「我建议，我是让你深入浅出，从形象的画面渐渐的深入下去挖，挖到那些基础基本的深层的概念，把每个东西都讲细。比如说 MC Dropout，你就得把 M 是什么？C 是什么？Dropout 什么意思？他们都是怎么操作的？具体这个流程是怎么样子的？一定要讲的足够的细，我才能听得懂。」
  - 「我的意思不是说让你模棱两可的去给我做一些比喻。你现在讲的这个是小儿科，就是都是给小孩听的故事。……做科研需要你这种游戏吗？我非常不满意，重做。」
  - 「把我真正想要的这种给我讲内容、讲知识的模式，死死的刻进你的记忆里，以后再也不要出现跟原来一样的失误。我不要听儿童故事，我也不要看见你那一堆晦涩难懂的生词自己在那硬猜。你要讲细，你要深入浅出，你要从形象到具体，从抽象到具体，从画面到数据。一定不要再犯这种错误了。」
  - 「后期我可能还会继续调整你对我的教学风格，你要时时刻刻的把我的每一次调整记录好，在你记忆当中留存好。以后你会是我很长时间一段的导师，你怎么教我东西，你必须得固定成一种模式和 skill。」
- **新禁令**：
  - 禁止成绩单 / 体检表 / 收得住 / 下雨天数 / 儿童游戏式类比当正文。
  - 禁止只讲大概。
  - 禁止丢未定义的生词让他猜。
  - 禁止用比喻替换定义。
- **新强制**：
  - 六层阶梯：画面 → 拆词 → 操作 → 公式 → 数据 → 边界与回收。
  - MC Dropout 必须拆到 M / C / Dropout，并写出流程。
  - 「收敛」必须分清：MC 估计量 / 覆盖率校准 / RANS 残差。
  - 74 维必须说成 9×8 全局统计约化 + Ω + P，不是成绩单。
  - 风格再调整：先写本日志，再改 skill。
- **作废**：`docs/DEFENSE_QA.md` 里 Q4「纠错（小白重讲）」那一档，以及 `docs/lecture-analogy-handbook.md` 作为对承泽 1:1 讲课术的地位。手册可留作对外讲座短类比，1:1 以 skill 为准。

## 2026-08-13 · A2 · 练习题型 选择:填空:问答 = 2:2:6

- **原话**：「你出的题咋全是主观问答？来一些客观题吧! 选择题：填空题：问答题比例为2:2:6」
- **新强制**：
  - 节末 10 题 = 2 选 + 2 填 + 6 问。
  - 单元卷 30 题 = 6 选 + 6 填 + 18 问。
  - 期末 40 题 = 8 选 + 8 填 + 24 问。
  - 选择一律四选一（A–D），有且仅有一个对。
  - 填空答案必须是教材里的法定词/冻定数，不能空到能瞎编。
  - 难度仍 2:7:1。
- **作废**：教材第一版「全是简答」。

## 2026-08-13 · A3 · 全书先认机器，禁止未定义开篇；打破两周锁死

- **原话**：
  - 「一上来出来一堆根本没见过的名词这对一个小白来说，每一句话我都理解不了」
  - 「啥是代理模型？什么叫已经训好的 ONNX 文件？什么是流出集上的 R 方表？什么是 SUR 日志？」
  - 「不许再随手生成」「全部的重塑，不止第一章」
  - 先验自选：高数入门可当桥；目录由技能定；打破两周宁长勿飘；验收=发送包十问+能指着仓库文件说话。
- **新禁令**：
  - 禁止在本章尚未定义的名词上开讲或出题（U01 不得考 PINN / TNO / conformal / Spearman）。
  - 禁止把证据档 E0–E4 放在「桌上三样东西」还没被认全之前当第一章。
  - 禁止口误式缩写不拆：SU2 不是 SUR；留出集不是流出集；relrms 必须先拆 relative / RMS。
  - 禁止 `null` 不定义就当答案。
- **新强制**：
  - 可当桥：导数、微分、向量、均值、标准差。马赫、等熵、RANS、神经网、代理、ONNX 必须从零定义。
  - 目录：机器与三个数 → 欧拉 → 激波附面层 → RANS → 74 维 → 代理网 → R² → MC Dropout → 覆盖率 → Pareto → 证据档与仓库 → 郭老师线。
  - 每章开头先给「先认词」表（中文 / 英文 / 一句操作定义），正文六层，章末「仓库指认」。
  - 练习只考本章已讲 + 前章已定义的词。
  - 日历服从深度，不服从「两周必须读完」。
- **作废 / 修改的旧条款**：
  - A0 里「马赫数、压力」一律可当桥：马赫数改为必须定义（压力、均值、std 仍可当桥）。
  - `docs/教材方案-两周突击.md` 的「D1 先读红线」作废，改为本条目录。

## 2026-08-14 · A5 · 教材必须零搜索可自学：定义闭环 + 术语依赖链 + 逐章重塑

- **原话**：
  - 「假设你现在先清空所有记忆，你就是一个刚刚高考考了650分擦线上了西交的幸运学生，你对大学完全没了解，老师一上来就把这全套教材的html扔到你面前，你能看懂吗？」
  - 「我说实话现在的教材还是完全无法用于自学。太多名词都需要我自己一边读教材一边搜索，而不是直接就能在教材里找到答案。」
  - 「你模拟一遍，完整读一遍，你一定会一头雾水的。所以，你必须进行一轮超级细化的重塑。」
- **新禁令**：
  - 禁止任何定义里出现未定义的词。定义用词必须 ⊆ 桥词 ∪ 本章前文已定义词 ∪ 显式标注「（U0X / §1.Y 才讲，这里只记名字）」。
  - 禁止先认词表自引用或顺序颠倒（旧 U01：总压定义里出现「等熵」，而等熵排在它后面）。
  - 禁止把「六层加厚过」当作自学可用。自检标准改判为：**650 分、零大学先验的读者，逐句读完不需要打开任何搜索**。
  - 禁止一屏并行抛多个概念；每节必须先列术语依赖链，再逐词展开。
  - 禁止公式里出现没当场给单位 / 数字例子的符号。
  - 禁止用「先认词表」代替正文逐词展开；表是索引，不是讲课。
- **新强制**：
  - 每章每节统一骨架：术语依赖链 → 逐词展开（中文 / 英文 / 符号 / 单位 / 一个数字例子）→ 正文（短句）→ 本节自检清单 → 练习 → 仓库指认（给出「打开哪个文件、看哪个字段」的具体动作）。
  - 桥词全集固定：压强、速度、温度、密度、质量、体积、力、功、位移、内能、比热容 Q=cmΔT、数学（比、百分数、导数、微分、向量、均值、标准差）。除此之外一律当场定义或显式标注后讲。
  - 电脑与仓库名词（仓库、目录、文件、路径、CSV、JSON、字段）在 U01 一次性给 mini 词表，全书共用。
  - 每个重要公式配一个代入具体数字的完整算例（如 π=2.05 → Δh₀≈66 kJ/kg 的逐步计算）。
  - 重塑顺序 U01→U12；每章重塑后立即重建 `教材/web/` 并推送。题号与 `教材配套答案详解.md` 不动，答案仍有效。
- **作废 / 修改的旧条款**：A4「只按章补洞、不要整本推倒」作废，改为按本条标准**整本逐章重塑**；00-怎么读这本书的「六层已加厚」表述同步改写。
