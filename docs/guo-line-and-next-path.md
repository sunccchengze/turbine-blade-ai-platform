# 郭老师路线图与我的下一步（2026-08-13）

> 依据公开论文与任职信息，不是组内未发表材料。若与组会口径冲突，以郭老师当面说的为准。

---

## 1. 郭老师这条线实际在走什么

把他的公开工作按时间串起来，不是「AI + 叶片」四个字，而是一条越来越贵、越来越少样本的设计链：

```text
叶轮机械 MDO（交大宋/李/丰）
    → 多保真代理：何时用 HF、何时掺 LF（2018 SMO，与 Haftka）
    → 并行多保真 EI / EGO 加点（2021 SMO）
    → 高维贵黑箱：KT-EGO（d>20）
    → 协同学习贝叶斯优化 CLBO（NTU DSAIR / Ong）
    → 涡轮多保真代理与 100+ 维叶栅差分进化（2023）
    → 物理增强神经算子：气膜冷却 SDNO（2024）
    → 全景神经算子 TNO：Rotor 37 先报 T,p,ρ 再报性能（2025 CJA 一区）
    → 气动热 / 流固 / 泵喷（2024–2025）
```

关键词是他的，不是网页的：**样本效率、保真度选择、加点准则、算子当 CFD 用、物理先验进网络**。

NTU DSAIR 那段，决定了他看学生时会先问：你少算几次真 CFD，能不能把设计空间探清楚？而不是：网页快不快。

## 2. 和我现在的错位

| 他现在的问题 | 我暑假停的位置 |
|---|---|
| 场算子（TNO）几乎当 CFD | 三个标量的残差 MLP |
| 加点：EI / 并行 MF-EI / CLBO | 离线 NSGA-II，点完不再问 CFD |
| 多保真：HF 少、LF 多，还要决定用不用 LF | 只有 PLAID 这一档，没有自己的粗/细网格对 |
| 几何是可优化的叶型 / 冷却布局 | 74 维场统计量，变不成 CAD |
| 下游已接灵敏度与优化 | 网页上的 5.4% 不能对外报 |

错位不是「我落后十年」，是我停在他 2015 年前后就会的标量代理，而他 2025 年已经把代理换成算子了。能接上的接口只有一个：**加点（infill）**。我的 η 覆盖率 65%，用他的话说，就是代理在激波附近不可信，下一个 HF 样本该落在哪。

## 3. 我感兴趣、也接得上他的下一步

不另起炉灶去训一个更小的 MLP，也不去撞 GeoFunFlow 那种三维生成模型。

**题目（内部用）：**  
跨音速压气机效率通道的校准加点——把欠覆盖的不确定度当成下一次细网格的采样器。

这就是把郭老师的 EGO/CLBO 语言，接到 Rotor 37 激波–效率这条物理伤疤上。

### 12 个月最小闭环

| 段 | 做什么 | 和他哪篇对话 |
|---|---|---|
| 第 1–2 月 | 精读 2018 SMO 多保真选数据集、2021 并行 MF-EI、2025 CJA TNO。把现有 UQ 表重写成「覆盖率–工况」图，标出激波附近失效带 | 他的选数据集问题 |
| 第 2–4 月 | 叶型改 CST 或 FFD（10–16 维）。保形预测把 η 名义 95% 区间校准到实测约 90%。几何不会改，选出的点仍不是叶子 | 高维贵黑箱的设计变量 |
| 第 4–8 月 | 主动学习 30–50 次收敛 RANS。采集函数用校准后的区间宽度或 conformal score，对照随机补点和纯代理 NSGA。只报 CFD 上的 Δη | 他的 EI / CLBO |
| 第 8–12 月 | 若进组：把残差网络先验换成他们的 TNO 场，加点准则留下。贡献变成「算子预报 + 校准采集 + 可制造几何」 | 2025 TNO 的下游 |

第一篇对外的落点仍是 Turbo Expo / 再扩 AST 或 CJA，摘要里必须有：设计变量维数、CFD 次数、细网格残差、CFD 的 Δη、相对随机补点的差。

### 明确不做

- 不把 0.23 ms 和网页当贡献；
- 不报代理 5.4%；
- 不在没 CST/FFD 之前谈「新叶型」；
- 不平行去啃三维生成模型。

## 4. 进组时怎么开口（接他的词，不接我的词）

「您 2018 年和 Haftka 老师问的是多保真该不该掺 LF。我现在卡在效率通道覆盖率只有 65%，想把这块当成加点传感器，先用几十次收敛 RANS 换一条能核的前沿。几何我改 CST。场预报我跟您 2025 年的 TNO 学，先不自己另做一套算子。」

这句话里有他的问题、我的切口、我不抢的东西。
