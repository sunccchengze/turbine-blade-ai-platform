## 1. 画面：叶栅里先发生了什么

先看图 A。这是跨音速压气机叶栅的一张剖面示意，不是你们网页上的 3D，也不是可加工 CAD。

- **叶栅**：一圈转子叶片在周向排开，相邻两片之间夹出一条通道。气从左进、右出。
- **相对来流 \(M_\mathrm{rel}>1\)**：站在叶片上看到的来流可以超音速。Rotor 37 叶尖相对马赫大约 1.4 量级（这是公开基准的典型数，不是我们自己跑出来的 E4）。
- **激波**：超音速流里的压力陡坎。几个网格宽度内，压强猛升、马赫数掉到亚音。图上那条红线是槽道激波。
- **附面层**：贴在叶面上的一层很薄的气。离壁面越近速度越慢，壁面上速度是 0（无滑移）。它是粘性剪切层，不是「叶子表面的油漆」。
- **激波–附面层干扰**：激波的逆压梯度打在吸力面（叶背）的附面层上。附面层变厚，严重时分离。分离区里掺混损失跳升。
- **等熵效率 \(\eta\)**：实际压缩过程离「可逆绝热」有多远。损失一跳，\(\eta\) 就跳。所以 \(\eta\) 对「激波站在弦向何处」极敏感，比总压比 \(\pi\)、质量流量 \(\dot m\) 更接近间断响应。

这一段的用处只有一句：后面 Dropout 再怎么抖权重，也抖不回「激波在哪」这件事。位置信息在进网络之前就被 74 维约化吃掉了。

74 维法定说法（以后不许再说成绩单）：

\[
x = \big(\Omega,\; P,\; \{\mathrm{stat}_k(\text{场}_j)\}_{j=1\ldots 9,\;k=1\ldots 8}\big)\in\mathbb{R}^{74}
\]

- 9 组场：CoordinateX/Y/Z，NormalsX/Y/Z，Pressure，Density，Temperature。每组是约 29773 个表面节点上的一个标量场。
- 8 个统计量：mean，**std**（标准差，不是方差），min，max，p25，p75，skew，kurt。
- \(\Omega\) 转速、\(P\) 背压是工况，不是从三万个点算出来的。

这是多对一映射：无数种「激波偏前 / 偏后」的表面场，可以有几乎一样的 Pressure_mean / Pressure_skew。网络看见的不是几何旋钮。

## 2. 拆词：M、C、Dropout 各自是什么

**Monte Carlo（蒙特卡洛）**  
用随机抽样去逼近一个解析上很难积出来的量。Ulam / von Neumann 在洛斯阿拉莫斯把随机试验当成数值积分器。名字来自摩纳哥的赌场，算法本身和赌博无关。

一维例子，只为钉定义：要算 \(\int_0^1 g(s)\,ds\)，就在 \([0,1]\) 上均匀抽 \(T\) 个点，用 \(\frac{1}{T}\sum g(s_t)\) 当积分。大数定律保证 \(T\to\infty\) 时这个平均值**收敛**到真积分。这里的「收敛」是 **Monte Carlo 估计量收敛**。

**Dropout（Srivastava et al., 2014）**  
训练神经网络时的正则化。每一个隐藏神经元的激活值，以概率 \(p\) 被乘成 0，以概率 \(1-p\) 留下（PyTorch 的 `nn.Dropout(p)` 还会把留下的值除以 \(1-p\)，叫 inverted dropout，保证期望不变）。

必须分清三个词：

| 词 | 是什么 | 在你们网络里 |
|---|---|---|
| **神经元** | 一层里的一个标量输出。线性变换 + 非线性（你们是 ReLU）之后的一个数 | 残差块里 256 维或 128 维向量的一个分量 |
| **权重** | 线性层矩阵 \(W\) 和偏置 \(b\)。训练要改的就是它们 | `nn.Linear` 的 `.weight` / `.bias`，整网约 52.3 万个参数 |
| **激活** | 当前这次前向里，某个神经元算出来的值 | Dropout 乘 0 的是激活，不是把 \(W\) 从文件里删掉 |

Dropout 的直接动作：改的是**这一次前向的通路**。权重还在。通路断了，等效于「这一次参与计算的有效权重」变了。说「晃的是权重」可以，前提是你能补出上面这句。

**MC Dropout（Gal & Ghahramani, ICML 2016）**  
把两件事接起来：推理时**不要**把 Dropout 关掉，对同一个输入重复前向 \(T\) 次，每次抽一套新的随机面具。用这 \(T\) 个输出的均值当预测、标准差当不确定度。

论文里的理论包装：Dropout 的随机面具相当于对权重放了一个 Bernoulli 变分分布，\(T\) 次前向是对后验预测做蒙特卡洛积分。包装可以后懂。算法本身就是上一句。

不要把这套东西叫「校准的 95% 置信区间」。证据文件里的法定名称是 **MC Dropout heuristic uncertainty band**。

## 3. 操作：对着你们的残差网逐步写

架构在 `notebooks/04_residual_physics_model.ipynb`：

```
输入 74
  → Linear(74→256) + BN + ReLU + Dropout(0.1)
  → ResidualBlock ×3  （256）
  → Linear(256→128) + BN + ReLU + Dropout(0.1)
  → ResidualBlock ×2  （128）
  → Linear(128→3)     → (π, η, ṁ)
```

每个残差块：

```
x → Linear → BN → ReLU → Dropout(0.1) → Linear → BN → (+x) → ReLU
```

`p=0.1` 的意思：这一层里每个激活独立地有 10% 概率变成 0，90% 留下并乘 \(1/0.9\)。

常规推理：`model.eval()`，Dropout 关闭，同一 \(x\) 永远得到同一个 \(y\)。这是网页上不点 UQ 时的那一点。

MC Dropout 推理（训练期实验，README「不确定性量化」节）：

1. 保持 Dropout 开启（`model.train()`，或等效地让 Dropout 在 eval 也采样）。
2. 固定同一条 74 维 \(x\)（已按 `scaler_X_v2` 标准化）。
3. 前向 \(T=100\) 次。第 \(t\) 次抽面具 \(z^{(t)}\)，每个该 Dropout 的位置独立 \(z_i^{(t)}\sim\mathrm{Bernoulli}(0.9)\)。
4. 得到 \(\{y^{(1)},\ldots,y^{(100)}\}\)，每个 \(y^{(t)}\in\mathbb{R}^3\)。
5. 对每个输出通道单独算 \(\mu,\sigma\)，画 \(\mu\pm 1.96\sigma\)。

生产路径 **不是** 上面这 5 步。`backend/app/model.py` 的 `predict_with_uncertainty`：ONNX 没有 Dropout 算子，用的是训练期平均 \(\sigma\) 的一张常数表（π 0.006393，η 0.001007，ṁ 0.061055），区间是 `mean ± 1.96 * sigma`。新来一个 \(x\)，带宽不会跟着这个 \(x\) 变。接口仍吃 `n_mc_samples`，但注释写明它不影响结果。这是工程折中，答辩时必须能自己讲出来。

## 4. 公式：μ、σ、1.96、覆盖率、三种收敛

对某一个输出通道（先盯住 \(\eta\)）：

\[
\mu(x)=\frac{1}{T}\sum_{t=1}^{T} y^{(t)}(x),\qquad
\sigma(x)=\sqrt{\frac{1}{T-1}\sum_{t=1}^{T}\big(y^{(t)}(x)-\mu(x)\big)^2}
\]

名义区间（把 \(\{y^{(t)}\}\) 当成高斯，取标准正态的 0.975 分位数 1.96）：

\[
I(x)=\big[\mu(x)-1.96\,\sigma(x),\;\mu(x)+1.96\,\sigma(x)\big]
\]

**经验覆盖率**（留出集 \(N=100\)，seed=42）：

\[
\hat C=\frac{1}{N}\sum_{i=1}^{N}\mathbf{1}\{\,y_i\in I(x_i)\,\}
\]

\(\hat C=0.65\) 的读法：100 个真值里，有 65 个落在各自的 \(I(x_i)\) 里。不是「模型有 65 分」，是区间这个物件的命中率。

三种「收敛」，现在可以钉死：

1. **Monte Carlo 估计量收敛**  
   \(\mathrm{SE}(\mu)=\sigma/\sqrt{T}\)。\(T=100\) 时约为 \(0.1\sigma\)。再把 \(T\) 加到 1000，\(\sigma\) 本身几乎不动。覆盖率失败**不是**采样次数不够。

2. **覆盖率校准收敛**  
   若 \(I(x)\) 真是 95% 预测区间，应有 \(\hat C\to 0.95\)（在与训练同分布的新样本上）。你们：π 0.89，η 0.65，ṁ 0.88。没有校准收敛。差得最多的是 η。

3. **RANS 残差收敛**  
   离散 N-S 的残差往下降，例如 relrms 到 \(-6\)。你们粗网格 SU2 `relrms=-3.39`，`converged=false`。这是另一件事。UQ 区间画得再漂亮，也不能给未收敛的 RANS 当挡箭牌。

1.96 从哪来：若 \(Z\sim\mathcal N(0,1)\)，\(P(|Z|\le 1.96)=0.95\)。它成立的前提是 \((y-\mu)/\sigma\) 近似标准正态，且 \(\sigma\) 没有系统性偏小。两个前提对 η 都不成立。

再深一层（方法局限，不是童话）：

- Dropout 只扰动**有效权重**。这叫认知不确定（epistemic）：换一套还说得通的参数，输出晃多少。
- 它不建模数据本身的跳（偶然不确定 / aleatoric），除非另做一个预测 \(\sigma\) 的头。你们没有这个头。
- Gal 的变分族非常窄。窄变分常常**低估**后验宽度。所以即使用对了公式，\(\sigma\) 仍可能偏小。这是方法的已知病，不是你们实现写错了。

`docs/fig14_uncertainty_vs_error.png`：η 上 \(\sigma\) 与 \(|\hat y-y|\) 的相关系数约 \(0.027\)。带宽几乎不跟踪谁更难。即使以后用保形把平均宽度拉到能盖 95%，「哪个点更不可信」这个排序对 η 仍然弱。这是主动学习为什么不能只看 \(\sigma\) 的伏笔。

## 5. 数据：冻结的数，和为什么是 η

`evidence/metrics.json` → `mc_dropout_heuristic`：

| 通道 | 平均 \(\sigma\) | 经验覆盖率 | 名义 |
|---|---|---|---|
| π | 0.0064 | 0.89 | 0.95 |
| η | 0.0010 | **0.65** | 0.95 |
| ṁ | 0.0611 | 0.88 | 0.95 |

η 最差，三件事叠在一起：

1. **物理**：激波–附面层让 η 接近间断。相邻几何可以差一个分离泡，效率掉一截。
2. **表示**：74 维全局统计把「激波在弦向何处」抹掉。网络是分段线性连续函数（ReLU 拼起来），用平滑曲面去贴一个接近跳的响应，残差会在跳的附近堆起来。
3. **方法**：Dropout 只在这块平滑曲面上抖权重。附近的有效权重给出差不多的 η，于是 \(\sigma\) 很小（平均只有 0.0010），真值已经跳到带子外面。

π 和 ṁ 对激波位置没有那么尖，覆盖率接近 90%，仍不到 95%。所以问题是系统性低估，η 只是最重的通道。

对照图 `docs/fig12_uncertainty_bands.png`：黑线是按真值排序的 100 个点，色带是 \(\pm 1.96\sigma\)。η 那张色带很窄，黑线多次穿出——那就是 35 个未覆盖点的样子。

## 6. 边界：保形补哪一块，不补哪一块

`backend/scripts/calibrate_uq_p2.py` 写的是 split conformal，套在 Deep Ensemble 的 \(\mu,\sigma\) 上。思想对 MC Dropout 的 \(\mu,\sigma\) 同样适用。

校准集上算非一致性分数

\[
s_i=\frac{|y_i-\mu(x_i)|}{\sigma(x_i)}
\]

取有限样本分位数

\[
q=\mathrm{Quantile}_{\lceil(n+1)(1-\alpha)\rceil/n}\big(\{s_i\}\big)
\]

以后的区间

\[
C(x)=\big[\mu(x)-q\,\sigma(x),\;\mu(x)+q\,\sigma(x)\big]
\]

若 \(q>1.96\)，这就是**加宽**。它把「名义 95%」改成「在与校准集可交换的新样本上，覆盖率有有限样本下界 \(\ge 1-\alpha\)」。

它补的：覆盖率校准收敛这一层。诚实。

它不补的：

- 不把激波位置补回 74 维。
- 不让 ReLU 网学会间断。
- 不让 fig14 里那个 \(r\approx 0.027\) 变成强相关（均匀加宽救的是平均命中，不是点排序）。
- **不**在分布漂移下仍给保证。Pareto 到训练集最近邻距离约是训练集内部的 3 倍（`nsga2_surrogate.manifold_note`）。校准集与 Pareto 边上的点不可交换，\(q\) 可以失效。
- 不代替 RANS 残差收敛，更不把 0.9173 变成一片金属叶子。

P2 脚本跑过的 93.5–96.5% **没有**写入 `evidence/metrics.json` 的冻结块，列在 `do_not_freeze_until_reproduced`。对外不许当结论。
