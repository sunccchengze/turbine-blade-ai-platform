# 全站 UI 审计 D43

## 用户标准

- 第一优先级：科研可信度；个人偏好：视觉有记忆点。
- 不满排序：高级感 > 页面统一 > 颜色/排版 > 信息层级 > 工程软件感。
- 参考：Linear、Vercel、Claude。

## D43 设计原则

1. 先让用户理解证据，再让用户操作模型。
2. 页面只保留一个主要动作，其他动作降级为辅助。
3. 用细线、留白和排版制造高级感，不用渐变和发光制造“科技感”。
4. 流场视觉只作为数据和结构的视觉隐喻，不伪造 CFD 场结果。
5. 所有页面共享同一套容器、间距、标题、状态和主题 token。
