## 1. 总体学习目标

学习结束时，不要求一开始就成为燃气轮机专家，而要求达到五个可检验结果：

1. 能用自己的话解释燃气轮机、压气机、燃烧室、涡轮和叶片的作用。
2. 能看懂本项目的主要量：压比 π、效率 η、质量流量 ṁ、转速 Ω、压力 P、温度和速度。
3. 能理解速度三角形、Euler 叶轮机械方程、级负荷、反动度、失速/喘振、边界层、激波和损失的基本关系。
4. 能解释“代理模型预测”与“真实 CFD/RANS 结果”的差异，并知道为什么必须做交叉验证。
5. 能围绕“AI 赋能的燃气轮机叶片多学科设计优化”向宋立明教授、郭振东老师进行清楚、诚实、有技术边界的交流。

## 2. DeepTutor 式学习闭环

每个模块不采用“看一堆资料然后自我感觉学会”的方式，而采用统一循环：

```text
诊断 → 建立知识地图 → 人话解释 → 精确公式/图示 → 项目映射
→ 5 道小测 → 错误分类 → 针对性补课 → 费曼复述
→ 间隔复习 → 综合任务
```

### 错误分类

每次答错记录为：

- **记忆错误**：不知道名词或公式；
- **理解错误**：背过定义，但不明白机制；
- **应用错误**：概念懂了，但不会放进项目；
- **边界错误**：把代理模型、点云、CFD 或物理事实混为一谈；
- **元认知错误**：不知道自己不懂，过早自信地给出结论。

最后一种尤其重要：科研中“知道自己不知道什么”比背更多术语更重要。

## 3. 学习阶段

### Phase 0：学习者基线诊断

启动时先不讲课，先做一套 20 分钟诊断：

- 你能否画出燃气轮机三大部分？
- 空气为什么要压缩？
- 压气机和涡轮有什么不同？
- 叶片为什么会产生压力差？
- 什么叫效率？
- CFD 在算什么？
- R² 能否证明物理模型正确？
- 代理模型为什么不能直接替代 CFD？

输出：个人知识地图、薄弱点清单和第一轮学习顺序。

### Phase 1：燃气轮机和叶轮机械直觉

目标：先建立物理直觉，不急着推复杂公式。

知识点：

1. 能量守恒与热力学循环；
2. 燃气轮机的压气机—燃烧室—涡轮链路；
3. 轴流与径流叶轮机械；
4. 转子、静子、叶盘和叶片；
5. 流量、压力、温度、速度和转速；
6. 压比、效率、功率和损失；
7. 为什么叶片气动设计影响整机性能。

项目任务：用三分钟向完全外行解释本项目为什么研究叶片，而不是先研究整台发动机。

### Phase 2：流体力学基础

目标：理解气流如何绕过叶片，以及压力、速度和损失如何产生。

知识点：

1. 流体、控制体和流线；
2. 连续性方程；
3. 动量方程；
4. 能量方程；
5. Bernoulli 直觉及其适用边界；
6. 边界层、分离和尾迹；
7. 湍流与平均化；
8. 跨声速流动和激波；
9. 为什么数值仿真需要网格和边界条件。

项目任务：看一张叶片压力分布图，指出哪里可能存在加速、减速、分离或高损失风险。

### Phase 3：轴流压气机与涡轮

目标：能听懂叶轮机械课题组最基本的技术对话。

知识点：

1. 绝对速度、相对速度和牵连速度；
2. 速度三角形；
3. Euler 叶轮机械方程；
4. 级负荷和流量系数；
5. 反动度；
6. 叶栅、叶型、弦长、弯度、厚度和安装角；
7. 压气机级与涡轮级的能量交换差异；
8. 失速、旋转失速和喘振；
9. 设计点、非设计点和工作范围。

项目任务：解释为什么改变叶片几何可能同时改变 π、η 和 ṁ，并且三个目标不一定同时变好。

### Phase 4：CFD、RANS 与 Rotor 37

目标：准确理解当前项目的技术载体。

知识点：

1. CFD 的输入、求解和输出；
2. 网格、边界条件、收敛和残差；
3. Navier–Stokes 方程的角色；
4. RANS 的基本思想；
5. 湍流模型的作用和局限；
6. NASA Rotor 37 是什么；
7. 压气机基准与涡轮背景的区别；
8. 为什么公开基准适合方法验证；
9. 为什么别人的求解器结果不能直接当作本项目的实验结果。

项目任务：读懂一个真实 SU2 case 的 cfg、网格说明和收敛日志，判断它是否真的对应 Rotor 37。

### Phase 5：AI 代理模型与数据泄漏

目标：知道 AI 模型看到了什么、没看到什么，以及为什么测试分数可能骗人。

知识点：

1. 监督学习、训练集、验证集、测试集；
2. 特征、标签、标准化和反标准化；
3. MSE、MAE、R²；
4. MLP、残差网络和 ONNX；
5. 物理边界惩罚与真正 PINN 的区别；
6. 场量统计特征和目标泄漏；
7. field-conditioned 与 geometry-conditioned；
8. PointNet 的逐点特征和全局聚合；
9. 为什么 η 比 π/ṁ 更难。

项目任务：自己解释为什么输入已经有 Pressure/Temperature 时，不能把重建结果称为纯几何场预测。

### Phase 6：不确定性、多目标优化与 Pareto

目标：能把模型结果讲成科学证据，而不是广告数字。

知识点：

1. epistemic 与 aleatoric 不确定性；
2. MC Dropout、Ensemble 和 Conformal Prediction；
3. 覆盖率与区间宽度；
4. 单目标与多目标优化；
5. 支配关系和 Pareto 前沿；
6. 代理模型外推和“钻模型空子”；
7. 数据流形、最近邻距离和可实现性；
8. 为什么 Pareto 特征向量不天然等于真实叶片。

项目任务：对 `pareto_evidence.json` 做一次口头答辩，主动说明证据支持了什么、没有支持什么。

### Phase 7：多学科设计优化与科研表达

目标：从“会讲项目”进步到“会提出课题问题”。

知识点：

1. 气动、结构、传热和控制之间的耦合；
2. 约束、目标、设计变量和可制造性；
3. 代理模型筛选—CFD 精算—数据回灌飞轮；
4. 主动学习；
5. 多保真建模；
6. 真实实验与数值验证的差别；
7. 研究问题、假设、方法、证据和局限；
8. 如何与导师讨论“我完成了什么”和“我还缺什么”。

综合任务：用 10 分钟向老师介绍本项目，并回答三问：

- 你的 Pareto 解能否造出来？
- 你的代理模型有没有 CFD 自证循环？
- 下一步最值得做的实验是什么？

## 6. 学习节奏

项目收口后，每次学习建议 45–60 分钟：

- 10 分钟复习上次错误；
- 15 分钟新概念讲解；
- 10 分钟项目代码/图表映射；
- 10 分钟小测；
- 5–15 分钟费曼复述和学习记录。

每完成 3 个模块安排一次综合复习；每完成一个阶段安排一次“给导师讲解”模拟。

**启动条件不变**：项目物理闭环和可实现性验证完成后，再正式启动系统学习。当前任务仍然是把项目做完、把证据做实。
