## 一、内阁裁决摘要（为什么这么改）

| 层 | 蓝图原案 | 30 天定稿版 | 改动原因（反对派指出） |
|---|---|---|---|
| P1 | 点云模型取代统计特征 | **双头融合**：点云编码器（场）+ 统计特征分支（标量） | 统计特征对标量极强，点云单挑大概率打不赢 → 不赌打赢，赌「不输 + 新增场能力」 |
| P2 | Deep Ensembles + Conformal | 不变 | 纯 Python、无 CFD 风险、修复 65–89% 硬伤 |
| P3 | 3D 全点云扩散 | **2D 扩散先通 → 3D 走 VAE 潜在空间**；失败降级=条件 VAE | 1,000 样本训 3D 扩散 = 模式坍缩高发区 |
| P4 | 完整 AI+CFD 数据飞轮 | **抽查验证模块**：只验 P3 top 5–10 解，时间盒 ≤5 天 | SU2 收敛 Rotor 37 是出了名的难，完整飞轮是 30 天里最大的时间炸弹 |
| E5 | LLM 助手 | MVP（API 调用 + 对话面板），最后做可砍 | 锦上添花不是地基 |

**对外叙事不变**：「从预测到生成 / 从数字到场 / 从承认不准到数学可信 / 从没跑过 CFD 到有验证链」——一个字都不用改，风险却砍掉 80%。

## 二、三个新的关键假设（必须先确认）

1. **GPU 通路**：执行 agent 在沙盒（可能无 GPU），重型训练靠用户本地跑脚本回传，或租云 GPU。→ Day 1 必须确认。
2. **SU2 定位**：与 PLAID 商业求解器的差异定位为「相对趋势验证」（学术上站得住，写进讨论点）。
3. **数据增广**：点云旋转/噪声/变形增广，1,000 → 5k+ 样本，是救活 P1 与 P3 的共同杠杆。

### Day 39 晚间：P1 纯点云第一个真数据结果（17:24 记录）

**真数据（9 通道，1000 样本）纯点云训练，1024 点 / 15 epoch / CPU 148s：**
| 输出 | R² | 基线（74维MLP） |
|---|---|---|
| 总压比 π | **0.9200** | 0.9844 |
| 效率 η | **0.6076** | 0.9561 |
| 质量流量 ṁ | **0.9516** | 0.9827 |

**解读**：只靠「点云几何+工况」、无 74 维统计特征，π/ṁ 已达 0.92–0.95 → **空间信息可用**（课题关键实证）；η 低是「最难+epoch少」；多训（50epoch/2048点）预计显著提升。

**保底方案（已实现）**：`train_fused_p1.py` 双头融合（统计特征+点云→标量）——标量有 0.98 保底，点云头提供场预测独有增量。
