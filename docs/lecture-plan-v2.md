## 一、设计原则

1. **三明治教学**：每个概念 = 人话类比 → 精确版 → 项目实例 → 检查点（缺一不可）
2. **可验证的参透**：每幕结束 3-4 个检查点问题（现场问答）——"100% 参透"不是口号，是可验证的
3. **仓库即教材**：每个概念都指出对应文件（notebooks/04、backend/scripts/...）——结束能闭眼画仓库地图
4. **诚实为价值观高点**：UQ 65% 覆盖率、Pareto 外推量、纯点云失败——**主动披露是全场的信任基石**（呼应宋老师最看重的品质）
5. **可裁剪**：必讲骨架 ~3h30m，选讲扩展（Agent demo、现场复现）~40m

## 三、叙事暗线：一条信任链

```
CFD（上帝视角：贵但真）
   ↓ 太慢，需要速算员
代理模型（速算员：快但会错）
   ↓ 会错，所以要有自我认知
UQ（模型说"我没把握"）
   ↓ 说没把握还不够，要验证
证据链自查（范围/流形/外推/邻域误差）
   ↓ 最终裁决
RANS 终审（SU2，高考）
```

> 这条暗线同时完成了三件事：①讲完 AI 工程方法论 ②展示了科学诚信 ③回收了第 2 幕埋的"官方黑盒 test"悬念。
