# D43 视觉方向确认

## 用户选择

> B 为主，吸收 A 的文字排版和 C 的流场视觉。

## 方向定义

### B：Local Control Room，主骨架

- 温黑底色与工业控制室信息层级；
- 强化 `LOCAL / WASM` 本地推理状态；
- 用黄色表示关键 Gate 与待处理风险；
- 用青绿色表示模型、数据和运行状态；
- 页面优先回答“现在运行什么、证据到哪一步、下一步是什么”。

### A：Rotor Editorial，文字与排版

- 研究手册式的大标题和留白；
- 少用装饰卡片，多用规则线、编号和短段落；
- 具体数字、文件名、实验状态优先于泛化营销语；
- 让 About 与 Methodology 可以被读完，而不是只被扫过。

### C：Aerodynamic Field，流场视觉

- 用等高线、网格、扫描线和参数场作为视觉母题；
- 让 Explore、Optimize 和几何预览承担“流动”感；
- 不伪造真实 CFD 流场，装饰性图形必须标为视觉语言或数据可视化；
- 不用动效掩盖 RANS 未收敛事实。

## 证据约束

- Pareto 始终称为“代理模型预测候选”；
- coarse Stage Performance 始终标记为未收敛趋势；
- fine mesh 长跑受本机内存限制，不在页面上展示早期性能作为最终值；
- 当前公开站点使用浏览器 ONNX Runtime Web，不再以 API Live 作为运行状态；
- About 技术旅程以 D42/D43 当前实际阶段为准，不再停留在 Day 37。
