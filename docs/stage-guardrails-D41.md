## 1. 阶段总原则

> **先让物理结果追上文案，再让文案追上物理结果。**

当前平台的 R²、Pareto 最优值和大部分性能数字来自代理模型；在真实几何和 SU2/RANS 对照完成之前，它们不能被表述为物理事实或已验证的最优设计。

每次工作结束必须给变更标注一种证据级别：

- **E0 规划**：想法、路线或待办，未执行。
- **E1 静态证据**：代码、配置、文档或 dry-run 存在，但没有真实运行结果。
- **E2 代理/留出证据**：模型、留出集、统计证据可复现，但仍在代理模型世界内。
- **E3 物理交叉验证**：真实几何、网格、SU2/RANS 已运行并有可追溯输出。
- **E4 闭环证据**：多个代表性解完成 RANS 对照，并形成误差/趋势/可行性报告。

禁止把 E0/E1/E2 写成 E3/E4。

## 2. 当前阶段的硬性禁令

### 禁止 1：没有真实 RANS 前宣称“找到最优叶片”

- 当前允许：**代理模型预测的 Pareto 前沿/候选设计**。
- 当前禁止：**已找到物理最优叶片、CFD 已证明最优、效率真实达到 0.9173**。
- 解除条件：至少 1 个真实几何完成 RANS；阶段性可信结论建议至少 3 个代表性解。
- 当前证据级别：E2。

### 禁止 2：把逐维范围内误认为落在数据流形内

- 当前事实：Pareto 解逐维未超出 1000 组观测范围。
- 当前事实：Pareto 到训练样本最近邻距离中位数约 17.38，训练内部约 6.09，处于流形边缘。
- 表述必须同时包含距离/外推风险，不得只写“全部在训练范围内，所以可实现”。
- 解除条件：完成特征到几何解码、几何有效性、网格成功率和 RANS 收敛证据。
- 当前证据级别：E2。

### 禁止 3：把 74 维统计特征称为 CAD 设计变量

- 当前定义：74 维是表面场量/工况统计特征，不是天然 CAD 参数。
- 页面和论文必须区分“特征空间优化”“参数化几何”“真实 CFD 网格”。
- 解除条件：建立可审计的特征→几何反解和几何合法性检查。
- 当前证据级别：E1/E2。

### 禁止 4：把官方黑盒 test 写成官方 test R²

- 当前事实：官方后 200 组 test 缺少几何和输出标签，无法直接计算 R²。
- 主 R² 口径继续使用 1000 组内部留出集 `n=100, seed=42`。
- 官方 split 只能报告 train 一致性、工况范围和近邻标签 sanity check，除非获得有标签数据。
- 当前证据级别：E2（官方 split 的结构性核验），不是官方 test R²。

### 禁止 5：把 SU2 dry-run 当成 CFD 验证

- `run_su2_validation_p4.py --dry-run` 只能证明验证流程骨架能生成文件。
- 没有真实网格、真实求解日志、收敛指标和提取出的性能值，就不能写“RANS 已验证”。
- 当前证据级别：E1。

### 禁止 6：把预计算 σ 写成实时 MC Dropout

- 生产 API 当前是训练期预计算 σ 的 `mode=statistical`。
- `n_mc_samples` 是兼容参数，不改变生产结果。
- UQ 目前是相对置信度指示器，覆盖率实测 65%–89%，不是严格 95% 保证。
- 当前证据级别：E2。

### 禁止 7：在未重新验收前宣称前端/线上已正常

- 修改后必须重新安装前端依赖并执行 build/lint，必要时启动后端和浏览器检查。
- 后端修改合并后必须确认部署平台已 Redeploy，再验证 `/health`、`/model-info` 和 UQ 响应。
- 当前沙盒只可证明代码静态检查，不可替代线上验证。
- 当前证据级别：待验证。

### 禁止 8：为了 PPT 先制造漂亮截图，再补真实实验

- 图表必须来自可追溯的脚本输出或真实实验产物。
- 占位、合成数据、教程算例、Rotor37 真算例必须在文件名、图注和讲稿中明确区分。
- 如果实验未完成，展示“验证计划/当前缺口”，不能展示成“验证结果”。

### 禁止 9：把目标场作为输入后仍宣称“场预测”

当前 `rotor37_pc.npz` 的 9 通道包含 Pressure、Temperature；P1 场头的目标也包含 Pressure、Temperature。由此得到的场指标只能叫：

- 场重建；或
- 场条件融合诊断。

不得叫“几何+工况前向预测场”，除非输入屏蔽 Pressure/Temperature/Density 等目标相关场量，并重新训练、评估和报告。

同理，当前 74 维统计特征包含多个场量统计量。使用它们预测 π/η/ṁ 的结果属于“场统计特征条件下的代理预测”，不能不加限定地说成“仅由几何和工况替代 CFD”。

解除条件：建立无目标泄漏的 geometry-conditioned 输入版本，并与当前 field-conditioned 版本做并列消融。
- geometry-conditioned 输入：坐标 + 法向量 + 工况；
- field-conditioned 输入：保留 9 通道，但必须在结果和文案中明确标识。

### 禁止 10：一次性堆叠新模块，绕过 P4 最小闭环

当前优先级固定为：

1. Gate 0 基线复现；
2. 真实几何/网格/SU2 最小闭环；
3. 3 个代表性 Pareto 解对照；
4. 特征到几何可行性指标；
5. UQ 校准和主动学习；
6. 展示层更新。

任何偏离都必须记录原因，并通过“反对派”检查是否是在逃避最大风险。
