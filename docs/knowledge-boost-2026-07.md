## 〇、总纲：你要用一条「流水线故事」记住整台燃气轮机

**一句话记忆骨架（心智宫殿法）**：

> 空气从进气道进来 → **压气机**把空气压到几十倍大气压（压缩）→ **燃烧室**喷燃料点燃（燃烧，2026 年氢燃料是主角）→ 高温高压燃气吹动 **涡轮**旋转做功（膨胀）→ 剩余能量从喷管喷出形成推力（喷气）。→ 涡轮通过一根轴反过来带动压气机——这就是「燃气轮机 = 自己给自己打气、自己吹自己转」的机器。

- 四个环节：**压 → 烧 → 吹 → 喷**（首字母法，好记）。
- 你的项目（Rotor 37 压气机）就挂在「压」这一环上；你的三个输出（η 效率 / π 压比 / ṁ 流量）是全行业通用的三个「体检指标」，几乎任何前沿进展都能挂到这三个量上——**这就是你知识体系的枢纽**。

## 一、前置知识：燃气轮机与叶轮机械核心概念

### 1.1 热力循环：布雷顿循环（Brayton Cycle）

- 燃气轮机按**布雷顿循环**工作，四步：
  1. 等熵压缩（压气机，耗功）
  2. 定压加热（燃烧室）
  3. 等熵膨胀（涡轮，做功）
  4. 定压放热（排气）
- 理想循环热效率：η = 1 − 1/π_p^((γ−1)/γ)，其中 π_p 是**压比**。→ **压比越高，热效率越高**（极限是压比无穷大）。
- 真实循环里还有第二个提升点：**涡轮前温度 TIT 越高，效率越高**。所以全行业 70 年的进步就两条主线：**提高压比 + 提高 TIT**。

### 1.2 为什么 TIT（涡轮前温度）是「王者指标」

- TIT 演进：1950 年代 ~1,100 K → 2020 年代 **>2,000 K**——早已超过镍基合金熔点（~1,600 K）。
- 怎么活下来的？三件套：**内部冷却（对流）+ 气膜冷却（film cooling）+ 热障涂层（TBC）**，加上单晶叶片、陶瓷基复合材料（CMC）。
- 记忆口诀：**「膜-内-射-涂」**（气膜、内部对流、射流冲击、涂层）。
- 关联你的项目：**效率 η 是「温度潜力 × 气动质量」共同决定的**；你的 η 最难拟合（数据里变化范围只有 0.045）正是因为它被材料-冷却-气动多重因素压制在很窄的区间里。

### 1.3 压气机：你的主战场（Rotor 37 就在这里）

**单级结构**：转子（rotor，动叶，给气体加功）+ 静叶（stator，扩压，把速度能变压力能）。多级串联成「压气机」。

**关键概念（能讲出三个就算内行）**：
- **速度三角形**：绝对速度 C = 相对速度 W + 轮缘速度 U（矢量合成）。所有叶轮机械气动分析的地基。
- **流量系数** φ = Ca/U（轴向速度/轮缘速度）：衡量「气流多快」。
- **负荷系数** ψ = Δh/U²：衡量「一级干多少活」。负荷越高，越容易失速。
- **反动度** R：转子中静压升占总静压升的比例，轴流级典型 ~0.5。
- **de Haller 判据**：相对速度比 W₂/W₁ > ~0.72，低于此值气流分离（经验法则）。
- **扩散因子** D：静叶 ~0.6 上限、动叶 ~0.45 上限的经典经验值。

**跨声速**：叶尖相对马赫数 >1 时出现激波（Rotor 37 就是典型的**跨声速单级**：叶尖相对马赫 ~1.4）。激波带来损失，但允许单级压比做到 ~2（亚声速级只有 ~1.2–1.4）。

**失速与喘振（被问率极高的概念）**：
- **旋转失速（rotating stall）**：攻角过大 → 叶片吸力面分离 → 失速团沿周向传播。
- **喘振（surge）**：整体流动周期性反向（倒流），压气机「打嗝」，严重时结构损坏。
- 工程上所有压气机都有 **喘振裕度（surge/stall margin）**，设计时必须避开。**你的 NSGA-II 约束 π≥1.8、η≥0.84 就是在画「可行域」——和喘振裕度是同一个哲学：性能再诱人，也要先保证可工作。**

### 1.4 涡轮：高温的那一半

- 涡轮把燃气焓降转成轴功，多级，高压涡轮（HPT）+ 低压涡轮（LPT）。
- 与压气机相反：压气机是**对气流加功、减速扩压**；涡轮是**气流对叶片做功、加速膨胀**。
- 记忆对比：**压气机「挤」，涡轮「放」**。

### 1.5 性能指标（记这一组就够）

| 指标 | 含义 | 量级参考 |
|---|---|---|
| 总压比 OPR | 压气机出口/进口总压 | 现代大涵道比 40–60:1（GE9X 达 60:1） |
| 旁通比 BPR | 风扇流量/核心流量 | 老发动机 ~5:1，现代窄体 ~9–11:1，开式风扇目标更高 |
| 涡轮前温度 TIT | 燃烧室出口温度 | 现代 >1,700–2,000 K |
| 单位油耗 TSFC | 每磅推力每小时耗油 | 越低越好 |
| 热效率/推进效率/总效率 | η_total = η_热 × η_推进 × η_机械 | 推进效率 ≈ 2V₀/(V_e+V₀) |
| 推重比 | 推力/发动机重量 | 军用 ~7–11 |

**一句物理直觉**：推力 F = ṁ·(V_e − V₀)。**让更多的空气以较小的速度增量加速（大涵道比），比让少量空气喷得极快（小涵道比/涡喷），推进效率更高**——这就是民航机全部换成大涵道比涡扇的原因，也是「开式风扇/桨扇」的动机。

**Breguet 航程方程**（会背这一句）：航程 ∝ (V/TSFC) × (L/D) × ln(W_初始/W_最终)。→ 发动机省油（TSFC↓）直接转化为航程↑或载重↑，这就是「1% 油耗 = 几十亿美元」的行业逻辑。

### 1.6 航空发动机类型谱系（一张图记住）

```
涡喷 turbojet < 涡扇 turbofan（低涵道比 → 高涵道比）< 桨扇/开式风扇 open fan < 涡桨 turboprop < 涡轴 turboshaft
        军用战斗机                   窄体客机               RISE 目标              支线              直升机
   （速度优先）                 （效率优先，越靠右越省油、越慢）
```

- 军用战斗机用低涵道比 + 加力燃烧室（afterburner）——牺牲油耗换速度/推力。
- **自适应/变循环发动机（adaptive cycle）**：三涵道设计，巡航时开第三涵道省油（高涵道比模式），格斗时关闭第三涵道提推力（低涵道比模式）。代表：GE XA100 / PW XA101（F-35 的下一代候选、NGAD 六代机技术基础）。

### 1.7 发电用燃气轮机

- **简单循环**：H 级 ~42%+ 净效率。
- **联合循环 CCGT（燃气轮机 + 余热锅炉 + 蒸汽轮机）**：60–64%+。记忆阶梯：62.22%（GE 9HA，法国 Bouchain 创纪录）→ 63.08%（GE 7HA，日本西名古屋）→ **64.2%（Siemens SGT5-9000HL，英国 Keadby-2，吉尼斯纪录）** → 65%（行业长期目标）。
- 调峰逻辑：燃机爬坡快（Siemens 85 MW/分钟），是风电/光伏的最佳「补位」电源。

### 1.8 材料与制造（一句话一个点）

- **单晶镍基合金**（SX）：涡轮叶片，消除晶界弱化，允许更高温度。
- **热障涂层 TBC**（氧化钇稳定氧化锆 YSZ）：隔热层，表面温降上百 K。
- **气膜冷却**：叶片表面打孔出冷气，形成冷气膜。
- **CMC 陶瓷基复合材料**（SiC/SiC）：密度是镍基合金 ~1/3，耐温更高、可少冷却甚至不冷却。GE LEAP 首用 CMC 涡轮护罩，GE9X 用最多 CMC 部件。
- **复合材料风扇叶片**：GE90 首创（碳纤维），LEAP/GE9X 延续；钛铝化物（TiAl）低压涡轮叶片（GEnx）。
- **增材制造 3D 打印**：LEAP 燃油喷嘴（首个量产 3D 打印航空零件）、GE 9HA 燃烧部件（助力破 64% 效率纪录）。→ 给老师的例子：**「3D 打印从'做模型'变成'做核心件'，GE 的 HA 级燃机效率破纪录就有增材燃烧部件的功劳。」**

### 1.9 你的 Rotor 37 在行业坐标系里的位置（能背）

- NASA TP-1337（Reid & Moore, 1978），单级跨声速轴流压气机基准。
- 设计转速 17,188.7 rpm ≈ **1,800 rad/s**（你的数据 Ω 范围 1620–1800 rad/s 正好围绕设计点采样！这是你数据故事的第一句话）。
- 设计点：总压比 ~2.06、流量 ~20.2 kg/s、绝热效率 ~87.7%、叶尖相对马赫 ~1.4。
- 它是**全世界被 CFD 验证得最多的压气机之一**——所以选它做代理模型验证，审稿人/老师都认。

## 五、把前沿串到你的项目（被追问时的「高手话术」）

1. **「KIT 无压气机燃机和你什么关系？」**
   「KIT 用压力增益燃烧省掉了机械压气机，传统燃机约一半输出功用来驱动压气机——省掉后瓶颈就转移到了叶片气动效率本身。我的平台做的正是把叶片气动评估压到毫秒级，让这个瓶颈上的设计空间探索变得可行。无压气机时代，叶片效率就是一切。」

2. **「氢燃料会改变叶片设计吗？」**
   「会，而且方向明确：氢的绝热火焰温度更高、燃烧速度更快，涡轮前温度潜力更大——这对叶片是双刃剑：要么用更高温材料/冷却（CMC、气膜冷却），要么在同等 TIT 下把气动效率做到极致。所以 2026 年 KIT（燃烧侧）、空客-MTU（燃料电池侧）、AECC AEP100（氢直燃涡桨）三条路线同时推进时，气动代理模型反而更重要了——设计空间在扩大。」

3. **「开式风扇（RISE）和你的 74 维设计空间有关系吗？」**
   「有。RISE 开式风扇去掉机匣、用更大风扇和出口导叶重新设计气流组织，设计变量更多、气动-声学-结构耦合更强，纯靠 CFD 枚举式搜索不现实。CFM 自己说在用超级计算机做气动-声学优化——本质就是代理/数值优化思路。我的平台在 74 维空间演示的『代理 + NSGA-II』，正是这类高维问题的标准解法。」

4. **「你的物理约束是不是太弱？」（D31 Q3 加强版）**
   「现在是边界裁剪级，刻意分两段走。2026 年 4 月有篇 GE 9FA 燃机数字孪生论文，用守恒律约束神经网络、泛化更好——说明物理约束这条路线工业界在认真走。我的下一步就是把 N-S 残差或守恒律嵌进损失，做成真正的 physics-informed 模型。」

5. **「压气机数据、涡轮故事，是否混用？」（D31 Q5 加强版）**
   「压气机和涡轮同属叶轮机械，速度三角形、负荷系数、失速裕度这些概念和方法完全互通；而且 2026 年无压气机趋势下，涡轮/燃烧室正在'抢压气机的活'——方法学的边界在模糊，选公开基准 Rotor 37 恰恰是为了可复现。」

6. **「为什么效率最难拟合？」（Q4 加强版）**
   「效率被材料、冷却、气动、损失机制共同压制，在数据集里变化范围只有 ~0.045，信号弱；而且设计点附近的效率对损失细节极其敏感——这就是为什么我给效率 3× 训练权重。Rotor 37 设计点效率 87.7%，我的 Pareto 前沿推到了 91.7%，跨越的正是这 4 个百分点。」
