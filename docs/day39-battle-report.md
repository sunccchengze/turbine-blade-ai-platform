## 二、今天修的关键坑（已固化进文档）

1. **CellData 场量提取根因**：真实数据 CellData(29664) 字母序排前 → 场量长度不匹配被跳过 → 只 3 通道。修复：优先选与坐标同长数组。**9 通道验证通过**
2. **输入场量标准化**：Pressure ~1e5 直接进网络 loss 爆炸 → 3-8 列 per-channel 标准化，loss 从数万降到 6 量级
3. **CPU 陷阱**：2048 全量点 CPU 训练 60-75 分钟 → 加 `--n_points` 降采样，快 10 倍
4. **P3 check_valid 兼容真实翼型**：NACA 专用检查对抽取翼型误判 → 改轮廓非退化检查
