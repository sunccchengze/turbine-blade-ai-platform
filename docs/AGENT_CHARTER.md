## 最终状态（不是 Demo）

一个**知道自己什么时候可信、能输出真实几何、能接受 RANS 裁决、全过程可复现**的代理辅助气动设计研究原型。

理想闭环：

```text
可控几何参数
→ 合法叶片几何
→ 代理预测
→ 校准不确定性
→ 可信域：接受 / 谨慎 / 拒绝
→ 受约束多目标优化
→ RANS 复核
→ 回填 → 重训
→ 结论与证据同步
```

不是：预测很准、网页好看的叶轮机械 AI Demo。

## 十条

1. 评价代理时，R²/MAE/RMSE 不够。必须能谈排序、Top-k、可行性精度、HV 误差、regret、CFD 预算。
2. 第一轮 RANS 之后至少做一次小主动学习：高性能低不确定、高性能高不确定、普通对照；回填；看误差、UQ、前沿有没有动。
3. 做不到跨工况，就把结论缩到指定设计工况。禁止单点讲全工况。
4. 建失败地图：可信 / 谨慎 / 拒绝。系统必须能 abstain。
5. 公开数字只出自 `evidence/`。README、网站、API、论文、PPT 不得各写一套。
6. 关键 Gate 必须有未参与实现的 Reviewer，读数据、代码、原始输出和 RANS 日志，不读作者摘要。
7. 每过一个 Gate，给承泽一次 teach-back。他先答，Agent 只纠错，不代写。他明确要求重讲时，按 `技能库&准则/chengze-deep-tutor/SKILL.md` 六层讲完再回收；禁止儿童故事，禁止只给大概。风格调整追加 `docs/tutor-style-changelog.md`。
8. 不虚构引用、数据、实验、几何、审批、CFD。失败算例保留。
9. ARIS 等自动循环必须有轮次、花费、目录、停止条件。未批准不得买算力、发布、投稿、删原始数据。
10. 技能最小组队：research-expert-system、ARS-Codex、统计/UQ、PaperSpine、Nature Skills（证据冻结后才写）、ARIS（预算清楚后才开）。

## 三个毕业等级

| 级 | 名称 | 要有什么 | 当前 |
|---|---|---|---|
| 1 | 可信代理基准 | 严格划分、多种子、强基线、消融、校准 UQ、可复现训评 | 未达到（只有单一种子留出集） |
| 2 | 物理闭环研究原型 | 几何可映射、合法性、Top-k RANS、排名对比、Trust Region、一次主动学习 | **现实目标** |
| 3 | 可讨论论文贡献 | 非设计点或收缩结论、独立复现、样本效率、CFD 预算、决策指标、第二套数据 | 以后再说 |
